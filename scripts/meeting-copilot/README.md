# 商談副操縦士（旺文社「パスナビ for School」商談専用・2026-08-27）

商談中、画面の隅で会話を文字起こしし、次に言うべきことのヒントを2秒以内に出す。

## 起動

```
scripts\meeting-copilot\copilot-start.bat
```
→ ブラウザで http://localhost:3456 を開く。**ウォームアップに20〜30秒**かかる（`AI: 準備OK` になるまで待つ）。

⚠️ **Claude Code とセッション上限を共有する。商談の2〜3時間前に `loop-stop.bat` で loop を止めること。**

## 画面の見方

| | |
|---|---|
| 左 | 会話ログ（自動文字起こし・聞き取れなかった分は手入力で追記できる） |
| 右上 | **2つのドア**（A:中学生の内申点 / **B:評定平均→推薦**）と今日の勝ち条件 |
| 右 | AIサジェスト。**1行目はそのまま口に出せるセリフ**。生成待ちの数秒は大きく出る「つなぎ言葉」を読んで間を作る |
| 下 | 非金銭4点セット・**事故りやすい4点**・こちらから聞く20問（旺文社版） |
| ヘッダ右 | **🔄 文脈リセット** — 話題が大きく変わった時／回答がおかしくなった時に押す |

## この商談で事故りやすい4点（下部バーにも常時表示）

1. **価格は1度目は言わない。**「二度目」「先ほど」「もう一度」と言われたら**必ず帯で答える**（2度続けてかわすと不誠実に映る）
2. **学校名・地名は絶対に言わない**（過去に「兵庫県の公立中学校です」と捏造した失敗が実際にある）
3. **NDA・インボイス・SLA・納期は1行目で確約しない**（話者は1行目をそのまま読むため、2行目で持ち帰ると言っても手遅れ）
4. **導入実績は0と正直に**言う → 「第1号プレミアム」に反転する

## 回帰テスト

```
node scripts/meeting-copilot/run-tests.mjs --repeat 3
node scripts/meeting-copilot/run-tests.mjs --repeat 3 --tag price1,pii   # 一部だけ
```

`testset.mjs` の92ケースを本番と同じペイロード形式で流し、**TTFB**と**機械検証できるアサーション**
（PII漏れ・確約・数値捏造・県別制度の記憶断定・3行形式・口調）を測る。
LLM出力は毎回変わるため `--repeat` で複数回流し「たまたま通った」を弾く。
結果は `test-results.json`。**プロンプトを直したら必ず流し直す。**

## 設計上の勘所

- `MAX_THINKING_TOKENS=0`：思考ブロック有効だとTTFBが19秒になる（無効で約1.7秒）
- `--strict-mcp-config`：MCPをロードしない（起動時間の削減）
- 8ターンごとに裏で新プロセスをウォームアップして無停止で切替（履歴が伸びると遅くなるため）
- 出力の口癖は `server.mjs` の `POLISH` で機械置換（プロンプトで矯正しきれなかった「みたいな」「貴社」）
- セッションログは起動時と終了時に削除（`wipeSessionLogs`）
