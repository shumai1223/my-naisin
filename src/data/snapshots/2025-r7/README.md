# 2025-r7 スナップショット（令和7年度・収集中）

N1-2（`ops/tasks/T-N1-N4-revenue-ceiling.md`）で収集している前年度（令和7年度）の制度データ。
[[2026-r8]] と同じ正規形で47都道府県を埋め、N1-3の差分エンジンに実データを渡すための材料。

## 2026-r8との違い（重要）

- `2026-r8/` は「凍結」（生成後に書き換え禁止）だが、`2025-r7/` は**収集中でまだ完成していない**。
  1県ずつ一次ソースを確認しながら`entries`に追記していく運用のため、このディレクトリは
  完成（47/47県）するまで書き換え可能。完成したら凍結する。
- 47件揃うまでは `meta.status` が `"collecting"` のまま。完成後 `"frozen"` に変える。

## 収集方針（Y-0を継承）

- **推測で埋めない**。現存する教委サイトに令和7年度版のページ/PDFが残っていればそれを使う。
  残っていない県は Wayback Machine の CDX API で探す（[[fable5-fullaccel-backlog-2026-07]] X-14の実績手法）。
  それでも見つからない県は `entries` に加えず、`meta.unavailable` に「取得不能」として理由付きで記録する。
  2値化しない（[[exam-system-diff-types]]と同じ思想）。
- 各エントリの `diffFromCurrentYear` は自由記述のメモで、令和8年度（2026-r8）と比較して
  制度上の変更があったかを一次ソース確認の時点でその場に書き残す（N1-3の差分エンジン実行前の
  一次情報としても使える）。
- **大市場県（tokyo/kanagawa/aichi/osaka/saitama/chiba/hyogo/fukuoka）から着手**する
  （質問ノート2026-08-30 22:45指示）。途中で中断されても価値が最大になる順。
