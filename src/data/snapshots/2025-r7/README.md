## 収集方針（Y-0を継承）

- **推測で埋めない**。現存する教委サイトに令和7年度版のページ/PDFが残っていればそれを使う。
  残っていない県は Wayback Machine の CDX API で探す（[[fable5-fullaccel-backlog-2026-07]] X-14の実績手法）。
  それでも見つからない県は `entries` に加えず、`meta.unavailable` に「取得不能」として理由付きで記録する。
  2値化しない（[[exam-system-diff-types]]と同じ思想）。
- 各エントリの `diffFromCurrentYear` は自由記述のメモで、令和8年度（2026-r8）と比較して
  制度上の変更があったかを一次ソース確認の時点でその場に書き残す（N1-3の差分エンジン実行前の
  一次情報としても使える）。

  （質問ノート2026-08-30 22:45指示）。途中で中断されても価値が最大になる順。
