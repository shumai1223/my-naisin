# 2027-r9 スナップショット（令和9年度・**収集中・2026-09-07着手**）

T-Y11F §5順序#1（`ops/tasks/T-Y11F-publication-calendar-harvester.md`）で着手した、
次年度（令和9年度）の制度データ。[[2026-r8]]・[[2025-r7]]と同じ正規形。

## 2025-r7/2024-r6との違い（重要）

- R7/R6は「**過去**の年度のデータを遡って収集する」タスクで、理論上は47県すべてが収集可能
  （実施要項は既に発行・確定済みのため）。
- R9は「**未来**の年度のデータを先取りする」タスクで、2026-09-07時点では**一部の県のみ**
  R9実施要項・選抜要領を公表済み（多くの県はまだ発行していない）。
  そのため`meta.collectedCount`が47に近づくことは今季（T-Y11F payload window）では期待できない。
  **未公表はunavailableとは別の状態**（`meta.unavailable`には入れない・`meta.notYetPublishedNote`
  で区別する）。

## 収集方針（Y-0を継承・R7/R6と同じ）

- **推測で埋めない**。教委が実際に公表した一次資料（実施要項・選抜要領）のみを情報源とする。
- 各エントリの`diffFromCurrentYear`は自由記述のメモで、令和8年度（2026-r8）と比較して制度上の
  変更があったかを一次ソース確認の時点でその場に書き残す。
- 2026-08-31時点で公表確認済みとされた5県（埼玉・長野・大阪・神奈川・山口）から着手する。
