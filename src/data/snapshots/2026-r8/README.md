## 既知の未完了（正直な明記・N1-0の方針どおり）

- `pdfHash` は全件 `null`。47件分の一次ソースPDFを実際に取得してSHA-256を記録する作業は
  外部フェッチ47回分のコストがあるため、このスナップショット生成とは別イテレーションで行う。
  架空の値を入れることは捏造にあたるため入れていない。
- `sourceUrl` が必ずしもPDF直リンクとは限らない（教育委員会のポータルページの場合もある）。
  ハッシュ収集時にPDF本体のURLへの解決が別途必要になる県がある。
