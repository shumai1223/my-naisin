# Cowork指示書: 県教育委員会への「データ提供の可否」の問い合わせ（フォーム7県）

**作成: 2026-09-25（対話セッション）。送信は👤のみ。Coworkは確認画面で止めること。**

## 目的

年度末パック（令和9年度 公立高校倍率データの有償提供・`ops/tasks/T-TD1-nendomatsu-pack-sales-kit.md`）の
対象にできる県を増やすため、県の教育委員会に次の2点を確認する。
メール窓口の県は Gmail 下書きで対応済み（`ops/baselines/td1-license-asks-2026-09-25.md`）。
**この指示書は、問い合わせフォームしか窓口がない7県の分。**

## やり方（全県共通）

1. 下の「入口」を開く
2. 氏名: `國井 靖子`／メール: `naishin.dev@gmail.com`／件名: `公表資料（応募状況）の利用に関するご相談`
3. 本文: 下の「本文」の `{県名}` を置き換えて貼る
4. **確認画面まで進めて止める。送信ボタンは押さない**（👤が押す）
5. 電話番号・住所が必須の欄があれば**空欄のまま止めて**👤に報告（勝手に入力しない）

## 本文

```
{県名}教育委員会 入学者選抜ご担当者様

中学生向け内申点・偏差値計算サイト「My Naishin」（https://my-naishin.com）を運営しております、
しゅうまいと申します（中学生が個人で運営しております）。

貴課が公表されている公立高等学校入学者選抜の資料を一次資料として活用させていただいております。
次の2点についてお伺いできますでしょうか。

1. 貴課が公表されている「応募状況」（募集人員・応募者数・倍率等）の数値を、出典（資料名・URL）を
   明記したうえで当サイトに掲載することは差し支えございますでしょうか。

2. あわせて、当方で転記・整理した上記のデータを、新聞社や教育関連の事業者へ提供すること
   （有償の場合を含みます）は差し支えございますでしょうか。
   ・数値は公表値をそのまま転記し、改変や推計は一切行いません
   ・すべての行に出典を明記します
   ・公表資料（PDF等）そのものを配布するものではありません

いずれか一方でも差し支えがある場合は、その用途では{県名}のデータを使用いたしません。
ご多忙のところ恐れ入りますが、ご回答いただけますと幸いです。

しゅうまい / My Naishin 運営（中学生・個人開発）
https://my-naishin.com　naishin.dev@gmail.com
※ 契約・お支払いに関するお手続きは、契約名義人の國井が対応いたします
```
