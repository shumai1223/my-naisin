**正しい結論はこうだった**:

> 教科書会社は**窓口が複数ある**。最初に見つかるのが「見本請求」「採択関係」であることが多いだけで、
> **サイト内を探せば「一般の方」「お問い合わせ」窓口が存在する。**

第1弾で6社をスキップしたのは、**最初に当たった窓口だけを見て判断した**ため。
**「フォームという型が塞がっている」のではなく、「窓口の探し方が足りなかった」。**

→ **母数の下方修正は撤回する。** 教育出版・学参レーンは生きている。
→ 第3弾のプロンプト2章に「**まず窓口が複数あることを疑う**」を最上位のルールとして追加済み。
→ ⚠️ 教訓: **1回の失敗で構造的な結論を出すな。** 自分が昨日書いた
   「閉じたと言ってよいのは、同じ主体・同じ型に複数回試して全滅した場合だけ」を、自分が破っていた。

## 第2弾で新たに判明した4つの失敗パターン（第3弾のプロンプトに反映済み）

1. **本文中のURLがスパム判定で弾かれる**（アットシステム）
   → `https://` を外す → それでも駄目ならURL行を削除して記録
2. **フォームが途中でリセットされる**（浜島書店・コレオス・TOPPAN）
   → 入力後に全項目を目視確認して再入力
3. **ラジオボタンのクリックイベントが発火しない**（TOPPANのMarketo・アーテック）
   → JavaScriptで直接値を設定してよい（**送信はしない**）
4. **「導入予定台数／時期／製品型番」が必須＝既存顧客専用**（ガイアエデュケーション）
   → お客様番号と同じ扱いでスキップ
