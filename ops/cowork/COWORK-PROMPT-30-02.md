## 0. 最初に置き換えること（👤がCoworkに貼る前に、ここだけ手で書き換える）

以下を実際の値に置き換えてから貼り付けてください。**置き換えなかった欄では Cowork は必ず停止します。**

- `【氏名】` → 契約主体である親権者の氏名（例: 山田 太郎）
- `【氏名カナ】` → そのフリガナ（例: ヤマダ タロウ）
- `【電話番号】` → 連絡可能な電話番号（ハイフンあり）
- `【郵便番号】` → 例: 123-4567
- `【都道府県】` → 例: 東京都
- `【市区町村以下】` → 例: 千代田区○○1-2-3 ○○マンション101

⚠️ **住所は「特定商取引法の表記」でどのみち公開が必要になる情報**です。ここで使っても新たな露出は増えません。

## 1. あなた（Cowork）の役割

日本の教育系企業30社の**公式問い合わせフォーム**を1社ずつ開き、
**指定された本文を入力し、送信ボタンを押す直前の状態で停止**してください。

### 🚫 絶対にやってはいけないこと（最優先）

1. **送信ボタン・確認ボタン・「同意して送信」を押さない。** 送信は人間が行います。例外はありません。
2. **入力内容を勝手に書き換えない。** 本文は一字一句そのまま。要約・言い換え・改行削除をしない。
3. **書かれていない情報を作らない。** 実績・導入社数・受賞歴を創作しない。
4. **同じ会社に2回送信しない。**

### ✅ 各社での手順

1. URLを開く → 2. **目的一致チェック**（2章）→ 3. 入力（3章）→ 4. 必須項目の確認
→ 5. **スクリーンショット** → 6. **停止（送信しない）** → 7. 結果を1行記録 → 次へ

## 2. 目的一致チェック（入力前に必ず行う）

**第1弾では30社中11社がここで脱落しました。先に判定すれば時間を無駄にしません。**

### 入力せずスキップする（実際に第1弾で出たパターン）

- **採用・求人**専用／**IR・株主**専用
- **教科書の見本請求**専用（教科書会社に非常に多い。数研出版・くもん出版・昇龍堂で発生）
- **「教科書・指導に関すること以外は受け付けない」等の限定**が明記されている（教育出版で発生）
- **「営業目的のお問い合わせはお断りします」と明記**（learningBOX・Z会ソリューションズで発生）
- **塾専用・保護者/生徒専用**フォーム（総進図書・岐阜新聞情報センター・広島じゅくこーぷで発生）
- **取材・映像化・許諾申請**専用（Gakkenで発生）
- **取引申請フォーム**のみで問い合わせ窓口が無い（教育開発出版で発生）
- 個人のお客様専用／商品の不具合・返品専用／会員ログインが必要

### 入力してよい

- 「お問い合わせ」「法人のお客様」「事業に関するお問い合わせ」「提携・協業について」
- 「その他のお問い合わせ」で、種別に事業関連の選択肢がある

スキップした場合は理由を1行で記録し、**入力は一切行わずに**次へ。

### ★対応表に無い必須項目が出たときの判断ルール（第1弾で2社が止まった型）

第1弾では **KADOKAWA「当社の商品・サービス名」**、**東京書籍「都道府県・ソフト名/商品名」** で止まりました。
以後はこう判断してください。

| 型 | 対応 |
|---|---|
| **相手の商品・サービス名を選ぶ/書く欄** | **選択式**なら「その他」「該当なし」を選ぶ。**自由記述**なら `該当なし（新規のご相談のため）` と入力 |
| **都道府県**（自分の所在地を聞かれている） | `【都道府県】` |
| **業種 / 職種** の選択 | 「その他」。無ければ最も近いもの |
| **お客様番号 / 会員番号 / 契約番号** | **これがある時点で既存顧客専用フォーム** → 入力せずスキップ |
| 上記のどれにも当てはまらない | **推測で埋めず停止**し、欄の名前を記録 |

⚠️ **迷ったら「その他」を選ぶ。それも無ければ止める。作らない。**

## 4. 技術的な注意

- **reCAPTCHA / 画像認証**: 触らない。人間が送信時に行う
- **「入力内容を確認する」ボタン**: **押さない**。入力画面のまま止める
- **複数ページに分かれたフォーム**: 1ページ目だけ埋めて停止し記録
- **404・タイムアウト**: 30秒待って再試行、駄目なら記録してスキップ
- **文字数制限で本文が入りきらない**: **切り詰めず**記録してスキップ
- **改行が消えるフォーム**: そのままでよい

---

## 5. 本文について

各社の本文は、**その会社のサイトを実際に読んで1社ずつ書いたもの**です。テンプレートではありません。
**書き換えると価値が消えます。** 署名も含めて全部貼り付けてください。

## 6. 報告の形式

30社すべてが終わったら、**この表だけ**を出力してください。

```
| # | 会社名 | 結果 | 備考 |
|---|--------|------|------|
| 1 | 株式会社大阪進研 | 入力完了・送信待ち | — |
```

結果は次の4つのいずれか。

- **入力完了・送信待ち** … 必須項目が全部埋まり、送信ボタン直前で停止した
- **スキップ** … 目的一致チェックで対象外（理由を備考に）
- **停止** … 判断できない欄があった（**何という欄か**を必ず備考に）
- **到達不能** … ページが開かなかった
