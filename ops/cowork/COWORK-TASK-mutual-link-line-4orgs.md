# Cowork指示書: 相互紹介（相互リンク）打診4件をLINE公式アカウントで下書き（送信は👤）

## 背景

My Naishin（my-naishin.com）は中学生・保護者向けの公立高校入試の内申点・偏差値計算ツールサイトです。
運営者は現役中学生（しゅうまい）。以前のX-7（相互リンク構築プログラム・`docs/x7-mutual-link-outreach-2026-07.md`）で、
都道府県特化の学習塾・受験情報サイト4件との「対等な相互紹介（相互リンク）」の打診文面が既に用意されていましたが、
各サイトの問い合わせフォームがいずれも生徒氏名・学校名・電話番号等の個人情報必須（未成年の運営者は入力しない方針）
だったため送信できず、代わりにLINE公式アカウントでの送信に切り替えて`queued`のまま止まっていました。

loop（自動化された調査担当）はLINEアプリ・LINE公式アカウントを操作できないため、Coworkに下書き入力をお願いします。

## ⛔してはいけないこと

- **送信ボタン（送信矢印・Enterでの送信）を絶対に押さないでください。** 本文をLINEのメッセージ入力欄に
  入力した状態で止めてください。送信は👤（運営者本人）が内容を確認してから行います。
- LINEの「友だち追加」自体は必要であれば行って構いません（友だち追加のみでは相手に通知が届く形の
  メッセージ送信にはなりません）が、その先のメッセージ送信は行わないでください。
- 個人情報（生徒氏名・学校名・電話番号等）の入力は一切不要です。本文はそのままコピー＆ペーストしてください。
- 対外的な発信・SNS投稿等も不要です。
