## 0. 最初に置き換えること（👤がCoworkに貼る前に、ここだけ手で書き換える）

- `【氏名】` → 契約主体である親権者の氏名
- `【氏名カナ】` → そのフリガナ
- `【電話番号】` → 連絡可能な電話番号（ハイフンあり）
- `【郵便番号】` → 例: 123-4567
- `【都道府県】` → 例: 東京都
- `【市区町村以下】` → 例: 千代田区○○1-2-3 ○○マンション101

**置き換えなかった欄では Cowork は必ず停止します。**

## 1. あなた（Cowork）の役割

日本の教育系企業・団体36社の**公式問い合わせフォーム**を1社ずつ開き、
**指定された本文を入力し、送信ボタンを押す直前の状態で停止**してください。

### 🚫 絶対にやってはいけないこと

1. **送信ボタン・確認ボタンを押さない。** 送信は人間が行います。例外はありません
2. **入力内容を勝手に書き換えない**（例外は3章の「URLが弾かれる場合」のみ）
3. **書かれていない情報を作らない。** 実績・導入社数・受賞歴を創作しない
4. **同じ会社に2回送信しない**

### ✅ 各社での手順

1. URLを開く → 2. **窓口の選択**（2章）→ 3. **目的一致チェック**（2章）→ 4. 入力（3章）
→ 5. 必須項目の確認 → 6. **スクリーンショット** → 7. **停止（送信しない）** → 8. 結果を1行記録

## 2. 窓口の選択と目的一致チェック

### ★まず「窓口が複数ある」ことを疑う

過去の弾では、同じ会社の中に複数のフォームがあり、正しい方を選べば通った例が複数出ました。
→ **1つのフォームが不一致でも、すぐスキップしない。** サイト内に
  「お問い合わせ」「一般の方」「法人のお客様」「その他」の窓口が無いか**必ず探してから**判断する。

### 入力せずスキップする

- **採用・求人**専用／**IR・株主**専用
- **教科書の見本請求・採択**専用（他に一般窓口が無い場合のみ。**探してから**判断）
- 「**教科書・指導に関すること以外は受け付けない**」等の限定が明記されている
- 「**営業目的・マーケティング目的のご連絡はご遠慮いただいております**」と明記
- **塾専用**（塾コードの入力が必須／「学習塾の方」限定）
- **保護者・生徒専用**
- **既存顧客・導入検討専用**（下記★）
- 会員ログインが必要
- **フリーメール（Gmail等）でのお問い合わせを受け付けない旨が明記**されている（当方の送信元はGmailのため）

### ★「既存顧客・導入検討専用フォーム」の見分け方

次のいずれかが**必須項目**にあれば、そのフォームは既存顧客か導入直前の見込み客向けです。**スキップ。**

- お客様番号 / 会員番号 / 契約番号 / 塾コード
- **製品名・製品型番**（相手の商品を特定させる欄）
- **導入予定台数 / 導入予定時期**

→ ただし**任意項目**なら空欄のまま進んでよい。**必須のときだけ**スキップします。

| 資料請求 / メルマガ購読 | **チェックしない** |
| 個人情報の取り扱いへの同意 | **チェックする**（送信ではないので可） |

### ★本文が「URLを含む」と弾かれる場合

一部のフォームは、本文中のURLをスパム判定して**バリデーションエラー**にします。
→ そのときだけ、**本文中の `https://my-naishin.com` を `my-naishin.com`（httpsを外した形）に置き換える**。
　それでも弾かれる場合は、**本文からURLの行だけを削除**して送信直前まで進め、
　備考に「URLを除去した」と記録してください。**それ以外の書き換えは禁止です。**

### ★対応表に無い必須項目が出たときの判断ルール

| 型 | 対応 |
|---|---|
| 相手の商品・サービス名を選ぶ/書く欄 | 選択式→「その他」「該当なし」／自由記述→`該当なし（新規のご相談のため）` |
| 導入予定時期の選択 | 「未定」があれば未定。無ければ「来年度以降」 |
| 業種 / 職種の選択 | 「その他」。無ければ最も近いもの |
| **お客様番号・製品型番・導入台数が必須** | **既存顧客専用フォーム** → スキップ（2章★） |
| どれにも当てはまらない | **推測で埋めず停止**し、欄の名前を記録 |

## 4. 会社固有の注意（第6弾）

- **#1〜#5は地方紙（情報提供・取材依頼の窓口）です。** 「営業」ではなく「取材・寄稿の打診」なので、
  問い合わせ種別があれば「取材・その他」寄りを選んでください。
- **#4 琉球新報社**: reCAPTCHAが入っています。**送信直前で必ず止まり**、reCAPTCHAのチェック自体は
  行わないでください（人間が最終確認時に行います）。
- **#6〜#8は学会・業界団体です。** 営業文面ではなく「情報提供・データ引用のご相談」という低圧な
  フレーミングになっています。文面通りに入力してください。
- **#8 日本図書教材協会**: 個別企業ではなく「加盟社への取り次ぎ依頼」という文面です（備考欄に理由あり）。
- **#9〜#14・#28・#33・#34は教育専門メディア・業界紙・子育てメディアです。** いずれも「情報提供」の
  フレーミングで、押し売り文言を含みません。
- **#15 朝日学生新聞社**: フォームURLは `form.run`（外部フォームサービス）です。
- **#19〜#27は地域の学習塾協議会・団体です（都道府県単位の任意団体が多い）。** 本文は「加盟塾様への
  ご紹介」を依頼する共通テンプレートです。
- **#20 京都私塾連盟**: フォームURLが Google フォーム（`forms.gle`）です。
- **#21 かながわ民間教育協会**: フォームURLは `formzu.net`（外部フォームサービス）です。
- **#29 明蓬館高等学校**: フォームURLが Google フォーム（`docs.google.com/forms`）です。
- **#30 EduLab**: フォームURLは `form-mailer.jp`（外部フォームサービス）です。
- **#35・#36は教科書・教材出版社です。** 他の出版社(gakusan-*)と同型の文面です。

## 5. 報告の形式

全社が終わったら、**この表だけ**を出力してください。

```
| # | 会社名 | 結果 | 備考 |
|---|--------|------|------|
```

結果は次の5つのいずれか。

- **入力完了・送信待ち** … 必須項目が全部埋まり、送信ボタン直前で停止した
- **スキップ** … 目的一致チェックで対象外（**理由**を備考に）
- **停止** … 判断できない欄があった（**何という欄か**を必ず備考に）
- **到達不能** … ページが開かなかった
- **ページ側エラー** … フォーム自体が壊れていた（再訪問の対象）
