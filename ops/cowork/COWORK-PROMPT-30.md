## 0. 最初に置き換えること（👤がCoworkに貼る前に、ここだけ手で書き換える）

以下の3つを、実際の値に置き換えてから貼り付けてください。

- `【氏名】` → 契約主体である親権者の氏名（例: 山田 太郎）
- `【氏名カナ】` → そのフリガナ（例: ヤマダ タロウ）
- `【電話番号】` → 連絡可能な電話番号（ハイフンあり）

置き換えなかった場合、Cowork は該当欄で必ず停止して確認を求めます。

## 1. あなた（Cowork）の役割

日本の教育系企業30社の**公式問い合わせフォーム**を1社ずつ開き、
**指定された本文を入力し、送信ボタンを押す直前の状態で停止**してください。

### 🚫 絶対にやってはいけないこと（最優先）

1. **送信ボタン・確認ボタン・「同意して送信」を押さない。**
   入力が終わったら**必ず止まる**。送信は人間が行います。例外はありません。
2. **入力内容を勝手に書き換えない。** 本文は一字一句そのまま貼り付ける。
   要約・言い換え・敬語の調整・改行の削除をしない。
3. **書かれていない情報を作らない。** 実績・導入社数・受賞歴などを創作しない。
   欄が埋まらないなら空のまま報告する。
4. **同じ会社に2回送信しない。** 1社1回。

### ✅ あなたがやること

各社について、この順に実行します。

1. 指定URLを開く
2. **目的一致チェック**（下記2章）を行う。不一致なら**入力せずスキップ**して次へ
3. フォームの入力欄を、下記3章の対応表に従って埋める
4. 必須項目（`*` や「必須」表示）がすべて埋まっているか確認する
5. **入力済みの画面のスクリーンショットを撮る**
6. **そこで停止する。** 送信しない
7. 次の会社へ進む前に、下記6章の形式で1行の結果を記録する

---

## 2. 目的一致チェック（入力前に必ず行う）

**そのフォームが、今回の用件を受け付ける窓口かどうかを判断してください。**

### 入力してよい（用件が一致する）

- 「お問い合わせ」「法人のお客様」「事業に関するお問い合わせ」「提携・協業について」
- 「その他のお問い合わせ」で、問い合わせ種別に事業関連の選択肢がある

### 入力せずスキップする（用件が一致しない）

- **採用・求人**専用フォーム
- **IR・株主**専用フォーム
- **個人のお客様専用**／**商品の不具合・返品**専用
- **教科書の見本請求**専用（出版社に多い。用件が違う）
- **資料請求**専用で、自由記述欄がまったく無い
- **「営業目的のお問い合わせはお断りします」と明記**されている
- 会員・受検者専用（ログインが必要）

スキップした場合は理由を1行で記録し、**入力は一切行わずに**次へ進みます。

## 3. 入力欄の対応表

フォームによって項目名は違います。**意味が同じ欄に、下の値を入れてください。**

| よくある項目名 | 入れる値 |
|---|---|
| 会社名 / 法人名 / 団体名 / 組織名 / 貴社名 | `My Naishin（個人運営）` |
| 部署名 / 所属 | `個人運営のため部署なし` （必須でなければ空欄） |
| 役職 | 空欄（必須なら `運営者`） |
| お名前 / 氏名 / ご担当者名 | `【氏名】` |
| フリガナ / カナ / ふりがな | `【氏名カナ】` （ひらがな指定なら平仮名に直す） |
| メールアドレス | `naishin.dev@gmail.com` |
| メールアドレス（確認用） | `naishin.dev@gmail.com` |
| 電話番号 / TEL | `【電話番号】` |
| 郵便番号 / 住所 | **空欄。必須なら入力せず停止して報告**（勝手に埋めない） |
| ウェブサイト / URL / 貴社サイト | `https://my-naishin.com` |
| 件名 / タイトル / 用件 | 各社ブロックの「件名」をそのまま |
| お問い合わせ内容 / ご質問 / 本文 / 詳細 | 各社ブロックの「本文」をそのまま |
| 問い合わせ種別（選択） | 「法人」「事業提携」「サービスについて」等、**最も近いもの**。無ければ「その他」 |
| 資料請求のチェック | **チェックしない** |
| メールマガジン購読 | **チェックしない** |
| 個人情報の取り扱いへの同意 | **チェックする**（これは送信ではないので可） |

### 判断に迷う欄が出たら

**推測で埋めない。** その欄を空のまま残し、**何という欄で迷ったかを記録**して次へ進んでください。

## 4. 技術的な注意

- **reCAPTCHA / 画像認証**: 触らない。人間が送信時に行います。認証が入力前に必須で先へ進めない場合は、その旨を記録してスキップ
- **確認画面に進むボタン**（「入力内容を確認する」）: **押さない**。入力画面のまま止める
- **複数ページに分かれたフォーム**: 1ページ目だけ埋めて停止し、その旨を記録
- **ページが開かない・404・タイムアウト**: 30秒待って再試行し、それでも駄目なら記録してスキップ
- **文字数制限**で本文が入りきらない場合: **切り詰めず**、その旨を記録してスキップ（後で短い版を用意します）
- **改行が消えるフォーム**: そのままでよい。改行の有無で意味は変わりません

---

## 5. 本文について（重要）

各社ブロックの本文は、**その会社のサイトを実際に読んで1社ずつ書いたもの**です。
テンプレートではありません。**書き換えると価値が消えます。**

本文の末尾には署名が入っています。署名も含めて全部貼り付けてください。

---

## 6. 報告の形式

30社すべてが終わったら、**この表だけ**を出力してください。

```
| # | 会社名 | 結果 | 備考 |
|---|--------|------|------|
| 1 | 教育開発出版 | 入力完了・送信待ち | — |
| 2 | ○○ | スキップ | 採用専用フォームだった |
| 3 | ○○ | 停止 | 住所が必須だった |
```

結果は次の4つのいずれかにしてください。

- **入力完了・送信待ち** … 必須項目がすべて埋まり、送信ボタンの直前で停止した
- **スキップ** … 目的一致チェックで対象外と判断した（理由を備考に）
- **停止** … 判断できない欄があって埋め切れなかった（何の欄かを備考に）
- **到達不能** … ページが開かなかった
