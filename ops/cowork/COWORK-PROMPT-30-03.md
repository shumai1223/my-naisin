> 第1弾（送信10・スキップ11）から**送信数が2.3倍**になりました。効いたのは住所欄の追加とスキップ判定の明文化です。

## 0. 最初に置き換えること（👤がCoworkに貼る前に、ここだけ手で書き換える）

- `【氏名】` → 契約主体である親権者の氏名
- `【氏名カナ】` → そのフリガナ
- `【電話番号】` → 連絡可能な電話番号（ハイフンあり）
- `【郵便番号】` → 例: 123-4567
- `【都道府県】` → 例: 東京都
- `【市区町村以下】` → 例: 千代田区○○1-2-3 ○○マンション101

**置き換えなかった欄では Cowork は必ず停止します。**

## 1. あなた（Cowork）の役割

日本の教育系企業30社の**公式問い合わせフォーム**を1社ずつ開き、
**指定された本文を入力し、送信ボタンを押す直前の状態で停止**してください。

### 🚫 絶対にやってはいけないこと

1. **送信ボタン・確認ボタンを押さない。** 送信は人間が行います。例外はありません
2. **入力内容を勝手に書き換えない**（例外は3章の「URLが弾かれる場合」のみ）
3. **書かれていない情報を作らない。** 実績・導入社数・受賞歴を創作しない
4. **同じ会社に2回送信しない**

### ✅ 各社での手順

1. URLを開く → 2. **窓口の選択**（2章）→ 3. **目的一致チェック**（2章）→ 4. 入力（3章）
→ 5. 必須項目の確認 → 6. **スクリーンショット** → 7. **停止（送信しない）** → 8. 結果を1行記録

## 2. 窓口の選択と目的一致チェック

### ★まず「窓口が複数ある」ことを疑う（第2弾の重要な発見）

第2弾では、**同じ会社の中に複数のフォームがあり、正しい方を選べば通った**例が複数出ました。

- **大日本図書**: 「教員の方」向けをスキップし「**一般の方**」フォームから送信できた
- **光村図書**: 一度「利用許諾申請」に迷い込んだが、正しい「**お問い合わせ**」フォームに移って送信できた
- **晶学社**: 「参加塾掲載申込」は不一致だが、別の「**お問い合わせフォーム**」から送信できた

→ **1つのフォームが不一致でも、すぐスキップしない。** サイト内に
  「お問い合わせ」「一般の方」「法人のお客様」「その他」の窓口が無いか**必ず探してから**判断する。

### 入力せずスキップする（第1弾・第2弾で実際に出たパターン）

- **採用・求人**専用／**IR・株主**専用
- **教科書の見本請求・採択**専用（他に一般窓口が無い場合のみ。**探してから**判断）
- 「**教科書・指導に関すること以外は受け付けない**」等の限定が明記されている
- 「**営業目的・マーケティング目的のご連絡はご遠慮いただいております**」と明記（FLENS・learningBOXで発生）
- **塾専用**（塾コードの入力が必須／「学習塾の方」限定）（大阪進研・GSCで発生）
- **保護者・生徒専用**
- **既存顧客・導入検討専用**（下記★）
- 会員ログインが必要

### ★「既存顧客・導入検討専用フォーム」の見分け方（第2弾で新たに判明）

次のいずれかが**必須項目**にあれば、そのフォームは既存顧客か導入直前の見込み客向けです。**スキップ。**

- お客様番号 / 会員番号 / 契約番号 / 塾コード
- **製品名・製品型番**（相手の商品を特定させる欄）
- **導入予定台数 / 導入予定時期**（ガイアエデュケーションで発生）

→ ただし**任意項目**なら空欄のまま進んでよい。**必須のときだけ**スキップします。

### ★本文が「URLを含む」と弾かれる場合（第2弾で発生・アットシステム）

一部のフォームは、本文中のURLをスパム判定して**バリデーションエラー**にします。

→ そのときだけ、**本文中の `https://my-naishin.com` を `my-naishin.com`（httpsを外した形）に置き換える**。
　それでも弾かれる場合は、**本文からURLの行だけを削除**して送信直前まで進め、
　備考に「URLを除去した」と記録してください。**それ以外の書き換えは禁止です。**

### ★対応表に無い必須項目が出たときの判断ルール

| 型 | 対応 |
|---|---|
| 相手の商品・サービス名を選ぶ/書く欄 | 選択式→「その他」「該当なし」／自由記述→`該当なし（新規のご相談のため）` |
| 導入予定時期の選択 | 「未定」があれば未定。無ければ「来年度以降」（システムディで実証） |
| 業種 / 職種の選択 | 「その他」。無ければ最も近いもの |
| **お客様番号・製品型番・導入台数が必須** | **既存顧客専用フォーム** → スキップ（2章★） |
| どれにも当てはまらない | **推測で埋めず停止**し、欄の名前を記録 |

⚠️ **迷ったら「その他」。それも無ければ止める。作らない。**

## 4. 技術的な注意（第2弾で実際に起きたもの）

- **フォームが途中でリセットされる**（浜島書店・コレオス・TOPPANで発生）
  → **入力後に必ず全項目を目視確認**し、消えていたら再入力する
- **ラジオボタンのクリックが効かない**（TOPPANのMarketo・アーテックで発生）
  → クリックイベントが発火しない場合は **JavaScriptで直接値を設定**してよい。
  　ただし**送信は絶対にしない**
- **同意ページを経由してからフォームに着く**（実教出版・第一学習社で発生）
  → 個人情報保護方針への同意は**チェックして進んでよい**
- **送信後の遷移でエラーになる**（中央教育研究所で発生・`view.php` で通信エラー）
  → **フォーム側の不具合の可能性**。備考に「ページ側のエラー」と記録し、再訪問対象にする
- **reCAPTCHA / 画像認証**: 触らない。人間が送信時に行う
- **「入力内容を確認する」ボタン**: 押さない。入力画面のまま止める
- **404・タイムアウト**: 30秒待って再試行、駄目なら記録してスキップ
- **文字数制限で本文が入りきらない**: 切り詰めず記録してスキップ

---

## 5. 本文について

各社の本文は、**その会社のサイトを実際に読んで1社ずつ書いたもの**です。テンプレートではありません。
**書き換えると価値が消えます。** 署名も含めて全部貼り付けてください。
（例外は3章の「URLが弾かれる場合」のみ）

---

## 6. 報告の形式

全社が終わったら、**この表だけ**を出力してください。

```
| # | 会社名 | 結果 | 備考 |
|---|--------|------|------|
```

結果は次の5つのいずれか。

- **入力完了・送信待ち** … 必須項目が全部埋まり、送信ボタン直前で停止した
- **スキップ** … 目的一致チェックで対象外（**理由**を備考に）
- **停止** … 判断できない欄があった（**何という欄か**を必ず備考に）
- **到達不能** … ページが開かなかった
- **ページ側エラー** … フォーム自体が壊れていた（再訪問の対象）
