# Cowork指示書: 「倍率」語のGoogle Trends月次季節係数を実測してほしい

## 背景

My Naishin（my-naishin.com）は中学生・保護者向けの公立高校入試計算ツールサイトです。運営者は現役中学生。
現在、「〇〇高校 倍率」（志願倍率・競争率）というキーワード群への進出を検討していますが、この検索需要が
1年のうちどの月に最も伸びるか（季節係数）を実測したデータが社内にありません。

代わりに「内申点計算(S値)の2月係数=11.7倍」という**別のキーワードの数字を代理として流用**しており、
`ops/BAR.md`は「この代理値が2〜3倍しか合っていない可能性があり、その場合は投資判断の桁そのものが
変わる」と明記しています。loop（自動化された調査担当）はGoogle Trendsへ機械的にアクセスしようとしましたが、
`trends.google.com`が**HTTP 429（アクセス過多）を即座に返して一切データを取得できません**でした
（WebFetch・curl直接アクセスとも同じ結果）。これは実ブラウザでの手動アクセスなら通る可能性が高いため、
実ブラウザが使えるCoworkに依頼します。

## ⛔してはいけないこと

- **何も送信しない**。フォーム入力・登録・問い合わせは一切不要です。このタスクはページを開いて数値を読むだけです。
- 推測で数字を埋めない。読み取れなかった月は「不明」と書いてください（後述）。
- 対外的な発信・SNS投稿等も不要です。

## やってほしいこと

1. ブラウザで `https://trends.google.com/trends/explore?geo=JP&hl=ja` を開いてください。
2. 検索ボックスに以下のキーワードを**1つずつ**入力し、地域を「日本」、期間を「過去12か月」（可能なら
   過去5年で月次変化の再現性も確認）に設定して、表示される折れ線グラフの**月ごとの相対値（0〜100）**を
   読み取ってください。
   - `高校 倍率`
   - `〇〇高校 倍率`（例として実在の高校名を1〜2校入れてみて、パターンが同じか確認していただけると
     なお助かります。例:「日比谷高校 倍率」「湘南高校 倍率」等）
   - 比較用に、既に社内で数字がある `内申点 計算`（2月ピーク・代理値11.7倍の元ネタ）も同時に検索し、
     「倍率」系のグラフと山の形（ピークの月・急峻さ）を並べて比べてください。
3. 各キーワードについて、**月ごとのグラフの数値（目視でよい・スクリーンショットの座標読み取りでも可）**
   を報告してください。特に「1年で最も検索が多い月は何月か」「その月の値は、最も少ない月の何倍程度か」
   の2点は必ず埋めてください。
4. グラフが小さすぎて数値が読めない場合、「Googleトレンドを比較」ボタンでCSVダウンロードができる場合は
   ダウンロードして中身を貼り付けていただいても構いません（できなければ目視推定で問題ありません）。

## 一次ソースを優先してください

Googleトレンドの実グラフの数値そのものが一次ソースです。他サイトの「〇〇の検索時期はこの月」といった
二次的な解説記事の引用だけで済ませず、必ずご自身の画面でグラフを直接確認してください。

## 「不明」で構いません

429エラーでブロックされる・グラフが表示されない・データ量が少なすぎて信頼できない、等があれば、
遠慮なく「不明」「取得できず」と正直に書いてください。無理に数字を埋めていただくより、
「取れなかった」という事実の方が私たちには価値があります。

## 報告フォーマット

キーワードごとに:
- ピーク月（例: 2月）
- ピーク月の相対値とボトム月の相対値（例: 2月=100、8月=15 → 係数 約6.7倍）
- グラフの形の特徴（急峻な一峰型か、なだらかか、複数の山があるか）
- 気づいたことがあれば自由記述

最後に、「倍率」系と「内申点 計算」の山の形・ピーク月・倍率が**似ているか、大きく違うか**を
一言で結論づけていただけると、次のloopセッションがそのまま`ops/BAR.md`の代理値を差し替える
判断に使えます。

## 遠慮しないでください

いつも通り、褒める必要はありません。うまく読み取れなかった部分・矛盾する部分があれば率直に指摘してください。
