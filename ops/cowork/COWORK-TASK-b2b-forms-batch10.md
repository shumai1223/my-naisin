## 背景

My Naishin（my-naishin.com）は中学生・保護者向けの公立高校入試の内申点・偏差値計算ツールサイトです。
運営者は現役中学生（しゅうまい）。以前T-C1で「株式会社やる気スイッチグループホールディングス」
（スクールIE等4事業・国内外1,200教室以上）を調査した際、問い合わせページの5区分
（採用/フランチャイズ加盟/店舗設備/広告/その他）のうち誤って「広告について」（広告出稿検討者向け）
を選んでおり、送信対象から一旦見送っていました。

2026-08-30に再調査したところ、正しい窓口は「その他のお問い合わせ」
（`https://www.yarukiswitch.jp/inquiry/other/`）で、事業提携・法人からの提案を受け付ける窓口である
ことをWebFetchで確認しました。curlでも200応答（生存）を確認済みです。

## やってほしいこと

### 1. 株式会社やる気スイッチグループホールディングス

- 入口URL: `https://www.yarukiswitch.jp/inquiry/other/`
- 件名: 内申点計算データAPI/MCPのご案内（My Naishin）
- 本文（下記を使用）
- ⚠️問い合わせ区分の選択肢がある場合は「その他」に該当するものを選んでください（広告・採用・
  フランチャイズ加盟・店舗設備の窓口とは別です）。

```
株式会社やる気スイッチグループホールディングス ご担当者様

はじめまして。中学生向け内申点・偏差値計算サイト「My Naishin」を運営しております、しゅうまいと申します。

全国47都道府県の公立高校入試における内申点（調査書点）の計算方式を機械可読データ化し、
REST API / MCP（AIエージェント向け）として無料〜有償で提供しています。
https://my-naishin.com/developers

貴社が運営される「スクールIE」をはじめとする教室(国内外1,200教室以上)の進路指導・保護者面談の場面で使われる生徒情報の中に、都道府県ごとに異なる内申点の自動計算をAPIで組み込んでいただける余地があるのではと考えご連絡いたしました。

もしご興味をお持ちいただけましたら、まずは当サイトの内容や今後のデータ提供計画について簡単にご紹介させていただければ幸いです。押し売りする意図はございませんので、ご不要でしたら読み流していただければ結構です。

お忙しいところ恐縮ですが、ご検討いただけますと幸いです。

しゅうまい
My Naishin 運営（中学生・個人開発）
https://my-naishin.com
naishin.dev@gmail.com
```
