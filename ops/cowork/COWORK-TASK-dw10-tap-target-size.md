# Cowork指示書: タグ／チップ型リンクのタップ領域サイズを実ブラウザで確認してほしい

## 背景

My Naishin（my-naishin.com）は中学生・保護者向けの公立高校入試計算ツールサイトです。運営者は現役中学生。

`ops/DEADWIRE.md`のDW-10で、本番HTMLのclass名（Tailwindのpx-3/py-1.5等）から高さを**静的に推定**したところ、
`/hensachi`でボタン様要素112個中73個(65%)、あるブログ記事で86個中69個(80%)が「タップ領域44px未満」
（WCAG 2.5.8のガイドライン）に該当すると分かりました。ただしこれは**class名からの推定値**であり、
実際にブラウザで描画したときの本当のピクセルサイズではありません。loop（自動化された調査担当）は
実ブラウザでのレイアウト計測ができないため、Coworkに依頼します。

**優先度は低いです**（GA4のrage_click実測は全ページビューの2.3%で「急性の障害ではない」と判定済み・
主要な換金ボタンは既に44px以上確保されている）。急ぎではないので、手が空いたときで構いません。

## ⛔してはいけないこと

- **何も送信しない**。フォーム入力・登録・問い合わせは一切不要です。ページを見て測るだけです。
- コードの修正は不要です（それはloop側で行います）。
- 対外的な発信・SNS投稿等も不要です。

## やってほしいこと

1. ブラウザで以下の2ページを開いてください（スマートフォンの実機、またはブラウザのデベロッパーツールで
   モバイル表示に切り替えたもの、どちらでも構いません）。
   - `https://my-naishin.com/hensachi`
   - `https://my-naishin.com/blog/all-3-high-school-options-2026-update`
2. ページ内の「丸みを帯びた小さいタグ・チップのような見た目のリンクやボタン」（例: パンくずリスト・
   関連ツールへのリンク一覧・記事のタグ一覧など。文章中の下線付きテキストリンクは対象外です）を
   いくつか探してください。
3. デベロッパーツールの「要素を検証」（右クリック→検証）で、その要素（`<a>`か`<button>`タグ）を選択し、
   「Computed」タブに表示される実際の高さ（height、単位px）を確認してください。3〜5個ほど計測して
   いただけると十分です。
4. 実際にスマートフォン（または指でタップする想定）でそれらの要素をタップしてみて、押しにくいと
   感じるかどうかの主観的な感想も教えてください。

## 報告フォーマット

- 計測した要素ごとに: どのページのどの部分か（見出しやラベルで説明）／実際の高さ(px)
- 実測値がクラス名からの推定値(約24〜28px)と大きく違っていたら、その旨を教えてください
- タップしてみた際の使用感（問題なく押せる／少し押しにくい／かなり押しにくい）

## 一次ソースを優先してください

class名からの逆算ではなく、実際にブラウザが描画した値（デベロッパーツールのComputedタブ、
または実機でのタップ操作感）が一次ソースです。

## 「うまく測れなかった」でも構いません

デベロッパーツールの使い方が分からない、時間が取れない等があれば、無理せず正直に伝えてください。
気づいたことだけでも十分価値があります。

## 遠慮しないでください

褒める必要はありません。「思ったより小さい／大きい」「これは全然問題ない」等、率直な感想を歓迎します。
