# 夜間loopの起動手順（2026-11-06〜・Maxは11月いっぱい）

## 寝る前にやること（約1分）

1. PCを電源につなぐ。
2. 他のアプリ（Chrome・Spotify等）を閉じる（メモリ空きが少ないPCのため）。
3. VSCodeでこのフォルダを開いたまま、新しいチャットに下の1行を貼る。

```
/loop ops/LOOP_CONTRACT.md の「§0 夜間運転」に従い、主食の順に1項目ずつ進めよ。pushはしない。朝6:30までにdocs/worklogへ引き継ぎを書け。
```

## 朝にやること（約5分）

1. `docs/worklog/` の当日ファイルで、夜の成果・commit数・質問を読む。
2. `memory/loop-question-note.md` の冒頭に質問があれば、返事を書く。
3. pushしてよいか（1日1回・承認後）を決める。迷ったらpushしない。
4. 7:30〜7:50の定時タスクが動いたか確認（`docs/daily-brief.md` の更新時刻）。

## 止めたいとき

- 手動で完全に止めるときは `C:\Users\E24054\loop-stop.bat`。
- 夜に固まった場合は、朝にチャットを閉じて新しく始めれば足りる。

## 注意

- 夜の作業は**commitまで**。pushは朝以降に👤が承認した1回だけ。
- フタを閉じるとスリープしてloopが止まる設定のままだと、夜通し動かない。フタを開けたまま電源につなぐか、フタを閉じたときの動作を「何もしない」にする（変更は👤の許可で私が行う）。
- 利用上限に当たると待ちが出る。夜の実働は4〜6時間を見込む（実測前の見積もり）。
