# T-TD1 TD-10: 撤退判定の計測台帳（年度末パックの売り込み）

**👤が送ったら、下の表に1行足すだけ。** 判定は `node scripts/td1-funnel-judge.mjs` が表を読んで出す（10/31・11/30の判定式は下）。
1行 = 1送信（1組織へ1回）。返信・会話・購入意向・発注は、あった行に日付/1を書き込む。

- **`data/outreach-ledger.json` には新しい lane を足さない。** 既存の lane（`b2b-saas` / `chihoshi` / `media` など）を使い、送ったら通常どおり1エントリ追記する
  （lane の許容値は fail-closed のテストがある・2026-09-06に存在しない lane 名でテストを落とした前科）。この表はledgerとは別の、年度末パック専用の集計。
- 送り先は 11組織（`td1-target-list-2026-09.md`）。**250通ではない。** 分母は「実際に送った数」。

## 送信記録（ここに1行ずつ足す）

| 送信日 | 組織 | 窓口 | 返信日 | 返信の種類 | 会話 | 購入意向 | 発注 | 備考 |
|---|---|---|---|---|---|---|---|---|

- 送信日: `YYYY-MM-DD`。窓口: `メール` / `フォーム`。
- 返信日: 人間の返信があった日（**自動受付メールは返信に数えない**＝空欄のまま、備考に「自動受付のみ」）。
- 返信の種類: `断り` / `質問` / `見積依頼` / `その他`。
- 会話: 返信のやり取りが2往復以上、または通話・面談をしたら `1`。
- 購入意向: 見積依頼・「検討したい」の明言・稟議に上げる旨の返信があれば `1`。
- 発注: 発注書・見積承認・請求書の依頼があれば `1`。

## 判定式（事前固定・9/3の撤退条件を、送り先が11組織であることに合わせて読み替えた）

```
返信率   = 返信数（返信日が入っている行）÷ 送信数（送信日が入っている行）
反証(a)  【10/31】 送信数 ≥ 100 のとき: 返信率 < 1% なら「中止」
                   送信数 < 100 のとき: 1%は統計的に判定できない（1通=9%）。返信数 = 0 なら「中止」、1件以上なら「継続」
                   ※ 送信数 < 11 のときは「送り先を出し切っていない」ので判定保留
反証(b)  【11/30】 購入意向 = 0 社なら「中止」
反証(c)  【2027-01】 競合スキャンの再実行（td1-competitor-scan-2026-09.md 末尾）。同等品が ¥25万未満 で見つかれば価格を設計し直す
反証(d)  【判定済み】 2026-09-24 TD-0: 納品対象は9県（30県未満）。売り文句に県数を書かず県名を列挙する（td1-delivery-capability-2026-09.md）
```

⚠️ (a) の「送信数 < 100 で返信0なら中止」は、9/3の元の条件（250通で2件以下）を、分母が小さいことに合わせて**当方が読み替えたもの**。👤が10/31までに確認すること。
