取得元: Google Trends MCP（`scripts/lib/trends-client.mjs`）/ geo=JP / `today 5-y`（週次262行）を月平均へ畳んだもの。

⚠️ **Trends の値は「相対検索指数」であって「自サイトのクリック」ではない。** 別リクエスト同士の値は
比較できない（同一リクエスト内の複数キーワードだけが同一スケール）。**形は信じてよいが、高さは信じないこと。**

## 4. 都道府県別（直近12ヶ月・**その県の全検索に占める割合**の相対値）

⚠️ **絶対量ではない。** 人口の少ない県ほど上位に出やすい。**「東京より滋賀を優先しろ」という意味ではない。**
「その県では倍率クエリが相対的に重い＝入試の関心が高い」という読み方をすること。

**「高校 倍率」**: 滋賀100 / 新潟88 / 岡山86 / 茨城85 / 沖縄85 / 三重82 / 富山82 / 兵庫82 / 千葉80 /

大阪28 / 福井8(47位)

→ **三重は内申点3位の県。** `/mie/naishin` の -78%（T-G1 G1-2）はその県で起きている。

## 5. ツールの癖（次に使う人へ）

- `trends_related_topics` は**常に空配列＝死んでいる**（Google側）
- `trends_related_queries` は**生きている。ただし大ボリューム語のみ**。
  実測: 偏差値 top24件 / 高校受験 top25件 / 内申点 top8件 / **調査書 0件 / 高校 倍率 0件**
- `interestByRegion` の戻りは `{ regions: [{geoCode, geoName, values:{kw:n}}] }`
- `relatedQueries` の戻りは `{ results: { <kw>: {top:[], rising:[]} } }`
- 5キーワードまで。**2件以上入れたときだけ同一スケールで比較できる**
- 最小リクエスト間隔1.5秒・429は自動リトライ。連続で叩くとcookie再取得が入る
