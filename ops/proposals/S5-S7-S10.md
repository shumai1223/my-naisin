## 3. この群で円が出せなかった案の一覧と、出せなかった理由

| ID | 理由 |
|---|---|
| S5-1 | セキュリティヘッダは収益経路に直接作用しない。避けられるのは将来のブラウザ既定値変更に対するテール・リスクで、確率・影響とも未知数のため期待値化しない |

| S7-2 | オプション価値（実行可能性の確保）であり、価値が顕在化するのは冬に実際の公表イベントが起きたときのみ。差-5自体の価値は`ops/BAR.md`側の管轄で二重計上を避けた |
| S7-3 | コンテンツ充実度が検索順位・滞在時間・CTAクリック率のどの経路で価値を生むか自社にA/B前例が無く未測定。学校名×倍率クエリは既に高順位のため追加効果の余地自体が未分解 |
| S7-4 | 進行管理ドキュメントであり直接の収益効果を持たない |
| S10-1〜S10-6（全6案） | いずれもC8（fail-closed）に基づくリスク回避・コンプライアンス対応であり、円ではなく「疑いを消す」ことが目的。金銭化するとC11（天井を作るな）にもC1（証拠主義）にも反する未検証の期待値操作になるため、意図的に円換算しない |
