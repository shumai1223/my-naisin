## 3. 円が出せなかった案の一覧と理由

| ID | 理由 |
|---|---|
| S1-2 | ゼロサムのアーム差し替え（既存A/B実験内での配分変更）で、直接の期待値変化が無い。価値は情報（S11-3参照） |
| S1-3 | href失効という未発生の仮想イベントへの保険。発生確率が未知数のため期待値を算出できない |
| S1-4 | 現行ハードコードの解決先と`PLACEMENT_LEAD_OVERRIDES.futoukou`の解決先が既に一致しており、表示内容が変わらない（保守性のみの価値） |
| S9-1〜S9-5（全5案） | 測定基盤そのもの（表記ゆれ解消・trusted定義の厳格化・bot判定精緻化・通過率計測・実機検証発注）であり、円ではなく「今後のEV計算の正確さ」に効く。円換算しようとすると、まだ測定できていない値を仮定することになり、C1（証拠主義）に反する |
| S11-2 | トリガーが「3つの季節専用枠のいずれかがASPに承認される」という外部・未確定イベント。避けられる損失(クリック単価¥108〜240)は計算できるが、月次の円には母数(承認時期×季節クリック数)が未確定のため変換できない |
| S11-3 | 実験の運用手順を固めるだけで、実験自体（S1-2）が既に走っている。得られるのは`convRateLow`という係数の実測値であり、それ自体は円ではなく係数 |
| S11-4 | 「直す」方向自体が未確定（EVで見ると現状維持の方が高い）。変更を提案しないこと自体が本案の結論であり、円換算の対象がそもそも無い |
