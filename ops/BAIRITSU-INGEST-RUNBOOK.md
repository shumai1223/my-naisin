# 倍率取り込み運用手順書（T-Y11B 段階3）

**対象**: 冬（1月中旬〜2月下旬）に47都道府県教委が公表する令和9年度（R9）の高校別倍率PDFを、
`src/data/competition-rates/<pref>.ts`へ取り込むまでの一連の手順。

**前提（2026-09-02更新）**: 2026-09-01の着手前ゲートで「8県年中75%が要ビジョン解析」と判定した
のは`pdftotext`に`-enc UTF-8`を付けていなかった測定バグで、実際は47県中43県（91%）が機械抽出
可能と判明した（`ops/baselines/r8-pdf-parse-quality-2026-09-02.md`参照）。**したがってハイブリッド
設計（ビジョン解析フォールバックが主）は過剰設計だった。** 現在の方式は以下2段。

- ⚠️**2026-09-02 tochigiの検証で訂正**: 当初「学校名セルの結合が無い県は`pdftotext -table`
  だけで足りる」としていたが誤りだった。tochigiも学校名・学科名が「宇　都　宮」のように
  1文字ずつ均等割り付け（トラッキング）で組版されており、空白の数で列を判定する
  `\s{2,}`方式は列境界と文字間の空白を区別できず機能しない。**座標ベースの抽出
  （`scripts/bairitsu-ingest/extract-pdf-geometry.py`で文字座標を取得）が基本方針**、
  と訂正する。以下2パターンいずれも座標ベースだが、組み立て（assembly）ロジックが異なる:
  - **学校名セルの結合が無い県（tochigi型）**: 学校名ラベルは各学校ブロックの**先頭行**に
    だけ印字され、継続行は単に空欄になるだけ。`groupCharsIntoRows()`（罫線を見ずy座標の
    近さだけで行をクラスタリング）＋`extractRowFields()`＋`assembleSimpleTableRows()`
    （単純carry-forward）で組み立てる。107/107件・完全一致で検証済み（2026-09-02）
  - **学校名セルが複数学科行にまたがる「結合セル」を持つ県（ibaraki型）**: 学校名ラベルが
    結合セル内のどこか1行（先頭行とは限らない）にしか出現せず、単純な逐次スキャンでは
    正しく展開できない（下記「結合セルの解法」参照）。`parseTablePdfPageRows()`（罫線で
    行を区切りブロック境界も判定）＋`assembleCompetitionRateRows()`で組み立てる。
    149/149件・完全一致で検証済み（2026-09-02）
  - **判定の目安**: `pdftotext -table -enc UTF-8`の出力を目視し、学校名ラベルが各学校の
    先頭行にあるか、途中の行にあるかで選ぶ

ビジョン解析（Read toolによる目視転記）は、真にテキスト層が存在しないスキャン画像PDF
（fukushima等・少数派）に限定してよい。

### 結合セルの解法（2026-09-02・ibarakiのR8で149/149件・完全一致で検証済み）

学校名セルが複数の学科行にまたがる県では、学校名ラベルは結合セルの中央付近の1行にだけ
印字され、先頭行には出ない（PDF側の意図的な垂直中央揃え）。これはテキストストリームだけ
からは解けない（学科数からブロック境界を逆算する数式アプローチも試したが曖昧なケースで
破綻した）。**正しい解法は、罫線（ベクタ図形）から真のブロック境界を機械的に決定すること**:
学校名セルが結合されている箇所では、行区切りの罫線が学校名列をまたがず学科名列より右側
からしか引かれない。この「罫線のx0が学校名列の左端まで届いているか」だけで、結合セルの
範囲を機械的に判定できる。

**文字単位（word単位ではない）で抽出する理由**: PyMuPDFの`get_text("words")`はスペース区切り
で単語分割するため、学校名と学科名の間に実際のスペース文字が無いPDF
（例:「水戸桜ノ牧常北校」+「普通」がスペース無しで隣接）では1つのwordとして結合され、
列の取り違えが起きる。文字単位のbbox（`get_text("rawdict")`の`chars`）を列のx範囲で振り分け
れば、単語境界に依存せず正しく列を分離できる。

**半角カタカナの扱い**: PDFの埋め込みフォントによっては学科名が半角カタカナで抽出される
ことがある（例:「ｽﾎﾟｰﾂ科学」）。`.normalize('NFKC')`で半角→全角＋濁点/半濁点の合成まで
一括で正規化できる（`normalizeExtractedText()`）。

**列位置（茨城の例）**: `boundaries: [60.1, 114.6, 182.2, 223.6, 265.0, 306.4]`
（[学校名, 学科名, 募集定員, 志願者数, 倍率]の5列+右端）。**列位置は県ごとに異なる**ため、
新しい県に着手する際は`extract-pdf-geometry.py`の出力から罫線の縦線位置（別途
`page.get_drawings()`で`abs(x1-x2)<0.5`の線を集めれば得られる）を確認して決め直す。

## 手順

### 1. 検知

`scripts/check-competition-rate-updates.mjs`（A-2・2026-09-01実装済み・47県フルラン実機確認済み）
を実行し、各県の一次ソースページに新しい年度（R9）の公表資料が出ているかを確認する。

`src/lib/competition-rate-publication-baseline.ts`の公表カレンダー（`publishedAt`・44/47県分
判明済み）と突合し、**その県が公表しそうな時期（±数日）に集中して確認する**（毎日全県を
チェックする必要はない・相手サーバへの負荷軽減）。

### 2. 取得

- 一次ソースPDFのURLを取得する（`sources[]`の前年度パターンから類推できることが多いが、
  URLパターンが年度で変わる県もあるため、まず一次ソースのハブページを確認する）
- 相手サーバに負荷をかけない（1県1日1回・間隔800ms以上・UAを名乗る・robots.txt尊重）
- PDFをローカルに保存する

### 3. パース（2026-09-02更新: 罫線+文字座標方式）

1. `node scripts/check-r8-pdf-parse-quality.mjs`相当の判定（`-enc UTF-8`を必ず付ける）で
   `usable`と出た県から着手する。`ops/baselines/r8-pdf-parse-quality-<日付>.md`に前回の判定
   結果があるので、まずそれを確認する
2. **学校名セルの結合が無い単純な県**: `pdftotext -table -enc UTF-8`の出力をそのまま
   `\s{2,}`区切りでパースできる（列がずれない・継続行は先頭列が空になるだけ）
3. **学校名セルが結合されている県**（複数学科校で学校名が特定の1行にしか出ない）:
   `python scripts/bairitsu-ingest/extract-pdf-geometry.py <PDF> <ページ番号>`で罫線+文字座標
   のJSONを取得し、`src/lib/bairitsu-ingest/parse-table-pdf.ts`の`parseTablePdfPageRows()`→
   `assembleCompetitionRateRows()`に通す（列のx座標境界は県ごとに`TableColumnLayout`で指定）。
   ⚠️このPython側はPyMuPDF（`pip install pymupdf`）に依存する。この環境には導入済みだが、
   別環境で実行する場合は事前に確認すること（`pip show pymupdf`）
4. どちらの方式でも、**列構成が前年と同じ保証はない**（掛-1で毎年のように「学校名の行折返し」
   「くくり募集」「内訳行の混入」等の罠が見つかっている）。`src/lib/competition-rate-quota-definitions.ts`
   の該当県のquota定義（47/47県分・2026-09-01完了）を参照し、**同じ「倍率の分母と一致する列」を
   採用する原則**で列を同定する。ただし前年と列の並びが違う可能性は常に疑うこと
5. 真にテキスト層が存在しないスキャン画像PDF（fukushima等）のみ、`pdftoppm`で画像化し
   Read toolのビジョン解析で転記する（Y-6で47県分・複数年度で実証済みの高信頼度技法）

### 4. 検算

- `src/lib/competition-rate.ts`の`checkAgainstSubtotal()`（既存の再利用可能な純粋関数）で、
  自己集計と公式資料内のグランドトータル（または学科計）行を突合する
- **一致しない場合は数字を合わせにいかない**。「未解明差分あり」として明示的に記録する
  （gunma/hokkaidoの前例：2校の学校裁量枠差分等、正直な理由が説明できる場合のみ例外扱いを検討）
- 一致した場合のみ次へ進む

### 5. PR（データ追加）

- `src/data/competition-rates/<pref>.ts`に新しい`sources[]`エントリと`records[]`を追加する
  （既存の令和8年度データは残したまま、掛-1と同型で多年度に追加する）
- ヘッダコメントに一次ソースURL・公表日・抽出手法（テキスト抽出で成功／ビジョン解析が必要
  だった旨）・検算結果を記録する（次にこの県へ触れる回のための一次記録として残す）
- 対応する`__tests__/<pref>.test.ts`に新年度分のテストケースを追加し、
  `checkAgainstSubtotal`で緑になることを確認する
- `tsc --noEmit`実exit0・`npx jest`greenを確認してからcommit・push

### 検算が落ちたときに何を人間に上げるか

- **転記ミスの可能性が高い場合**（差分が特定の学校・学科の値と一致する等、原因が特定できる場合）:
  loop自身で修正し、修正過程をヘッダコメントに残す（ibaraki/gunma等の既存前例と同型）
- **原因が特定できない場合**: 数字を合わせにいかず「未解明差分あり」として`unresolved`相当の
  記録を残したままcommitしてよい（C8 fail-closed・Y-0憲法③捏造ゼロ）。👤への即時エスカレーション
  は不要（質問ノートに記録すれば足りる）が、**同じ県で3回連続して検算が落ちる場合**は
  資料の構造そのものが変わった可能性が高いため、質問ノートに「構造変化の疑い」として明記する

## 冬の実行ペースについて

「高校 倍率」の季節係数は2/07の週が年間最大（8月=1.00に対し24.14倍）。**1月に複数県が
同時公表するタイミングでは、この手順を1周回で1〜2県ずつ回すのが現実的**（1県ぶんの読解が
重い・Y-6実績でも1県あたり相応の時間を要している）。優先順位は
[[fable5-loop-protocol]]のLOOP_CONTRACT §0（期限のある作業を優先）に従い、**公表が早い県から
順に処理する**（`competition-rate-publication-baseline.ts`の公表カレンダーで確認できる）。
