## 3. 先に決めること（👤と親で）: どこまで自分を出すか

取材やコンテストでは、実名・顔写真・学校名を聞かれる。**前に校則を理由に、自分の学校が関わる動きを取り下げている**ので、線を先に決めておく。

### 大原則: 出す範囲は、あとから広げられるが、狭めることはできない

一度ネットに出た名前・顔・学校名は、記事を消してもらっても、検索結果・転載・スクリーンショットに残る。
**だから、最初は狭く始めて、必要になった場面で1段ずつ広げる。**

### 推奨

- **いまは段階1で始める。** Zenn・X・旺文社の紹介は、これで全部できる
- **段階2は、取材の申し込みが実際に来てから**決める
- ~~段階3は、2027年2月のプレスリリースかコンテストの前に、親と改めて決める~~ → **👤決定（2026-09-26）: 段階3は大学入試の直前に決める。** 2027年2月のプレスリリースとコンテストは**段階2（ハンドル名・顔なし）で出す**。実名が前提の新聞・テレビの人物記事は、それまで受けない（ウェブメディアはハンドル名で受ける）
- **段階4（学校名）は出さない。** 前に校則を理由に、自分の学校が関わる動きを取り下げている。出すなら、学校の許可を先に取ってから
- 住んでいる都道府県も、段階3までは出さない（実名や顔と組み合わさると、個人の特定につながる）

### 段階に関係なく決めておくこと

- [ ] **AIを使って作ったことは、必ず書く**（隠すと、分かったときに信用を失う。「中学生1人＋AIで、一次資料をどこまで正確に扱えるか」は、それ自体が記事になる）

- [ ] 取材を受けるときは、**記事が出る前に原稿を見せてもらう**ことを条件にする（名前・学校名が入っていないかを確認するため）
- [x] 段階: **2まで可**（2026-09-26 👤決定。後ろ姿・手元・画面・イラストの写真まで）。**段階3（顔・実名）は大学入試の直前に決める**。段階4（学校名）は出さない

**段階が決まった（2まで）ので、§4の5〜6も段階2の範囲で進めてよい。** コンテストは、応募書類に実名を書くこと（主催者だけが見る）と、受賞時に実名で発表されることを分けて確認する。発表が実名前提のコンテストは、大学入試の直前まで見送る。
