## 3. 先に決めること（👤と親で）: どこまで自分を出すか

取材やコンテストでは、実名・顔写真・学校名を聞かれる。**前に校則を理由に、自分の学校が関わる動きを取り下げている**ので、線を先に決めておく。

- [ ] 名前: 「しゅうまい」のみ／実名も可
- [ ] 顔写真: 出さない／出してよい
- [ ] 学校名・住んでいる地域: 出さない（推奨）
- [ ] 学年: 「中学3年生」「2027年春から高校生」まで出してよいか
- [ ] AIを使って作ったこと: **必ず書く**（書かないと、あとで分かったときに信用を失う。むしろ「中学生1人＋AIで、一次資料をどこまで正確に扱えるか」は、それ自体が記事になる）
- [ ] 取材の窓口: 保護者（契約名義人）を通すか

**決まるまで、報道機関への売り込み（§4の5〜6）はしない。**
