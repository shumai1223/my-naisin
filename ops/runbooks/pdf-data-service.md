## 4. 変換する

1. 一番近い型の `build_sample_*.py` を案件フォルダにコピーし、`SRC`(PDFのパス)と `META`(出典・資料名・URL・取得日・難しさ・方法・限界・目で見た範囲)を書き換える
   - 型の選び方: まず頁画像を見る → 罫線がきれいなら型B、列の区切りが点線/罫線なしなら型A、見出しの下に小列・斜線・複数頁なら型C
2. `build()` を作る。守ること:
   - **全セルにPDF上の矩形(bbox)を持たせる**(`cell(値, 頁番号0始まり, 矩形)`)。検算はこの矩形で行う
   - 縦の結合セルを下の行に引き継いだ値は `inh=True`(灰色の斜体で出力・検算の対象外)
   - PDFの文字と違う表記で出すセルは `verify_as=<PDF側の文字>` と `note` を付ける(例: 斜線→「（斜線）」は `verify_as=''`、見えない文字 U+00AD →「－」)
   - 作業側で付けた値(頁番号の列など)は `meta=True`
   - 見出し行の範囲を `header_areas` に入れる。表の外の題名・注記は `outside_blocks()` で別シートへ
   - 自己整合の確認(番号の連続・合計値など)があれば `self_checks` に入れる
3. `python <build_xxx.py>` 単体で走らせて、行を画面に出して頁画像と見比べる

### これまでに踏んだ罠(見本作りで実際に起きたもの)

| 症状 | 原因 | 対処 |
|---|---|---|
| 「神戸 普通科」が1セルになる(三重) | 列の区切りが点線で `find_tables` が拾わない | 単語の座標で列を決める(型A) |
| 「○ ○」が1セルになり、どの小列の○か分からない(栃木) | 小列の区切りが点線 | 縦罫線を `get_drawings()` で取り、1文字ずつ割り当てる(型C) |
| 1行目に「○○○○○○○」が集まる(栃木) | 縦に並んだ○が単語として1つにまとまる/結合セルがあると `find_tables` の行の矩形が何行分にも広がる | `rawdict` の1文字ずつの座標を使う・行の高さはその行の一番低いセルから取る |
| 斜線のセルが空欄と区別できない | 斜線は文字でなく図形 | 斜めの線を `get_drawings()` で検出して「（斜線）」 |
| 検算側だけ「別添」を読めない(栃木) | そのフォントに文字コードの対応表が無く、poppler に日本語の追加データ(Adobe-Japan1)が無い(`Missing language pack` と出る) | 食い違いとしてレポートに残し、理由と頁画像で確認したことを書く。表の中で起きたら頁画像で全件目視 |
| 〇(U+3007)と○(U+25CB)が混ざる | PDFがそうなっている | そのまま出す(検算は一致する)。依頼者に統一したいか聞く |

## 5. 検算する(3点セットを作る)

```
python scripts/pdf-table-service/make_sample.py <build_xxx(拡張子なし)> <出力フォルダ>
```
(案件フォルダのスクリプトを使うときは、そのフォルダを `PYTHONPATH` に入れるか、`scripts/pdf-table-service/` に一時的に置く)

出力: `pdf-page-N.png`(100dpi)・`<id>.xlsx`(データ・題名と注記・出典と凡例)・シートごとの `.csv`(UTF-8 BOM付き)・`REPORT.md`

**合格の基準(全部満たすまで納品しない)**:
- [ ] 食い違いセル = 0、または**全件に理由がある**(`META['mismatch_explained']` に書く)
- [ ] どのセルにも入らないPDFの文字 = 0(0でなければ取りこぼし。表の外の文字なら注記シートへ)
- [ ] 陰性対照3種がすべて「食い違いが増えた」(0のままなら検算が壊れている)
- [ ] 見出しの確認で出た文字は、列名を短くした理由で説明できる
- [ ] 自己整合の確認がすべて「一致」
- [ ] 頁画像と出力を見比べ、見た範囲を `META['visual_check']` に書いた(全行を見ていないなら、見ていない範囲も書く)

検算で分かること・分からないこと(レポートにも自動で書かれる):
- 分かる: 各セルの文字がPDFの同じ場所の文字と同じか(写し間違い・欠け・余分・別の行や列への入れ違い)、頁の文字がすべて出力に入ったか
- 分からない: PDFの文字情報そのものの誤り(だから目視が要る)、セルの中の文字の並び順の入れ替わり、内容の正しさ
