## ★★★ 本タスクの本体＝「連絡経路の判別」（過去に最も時間を溶かした場所）

**既知の失敗**: 過去タスクで、**受験生・保護者向けの問い合わせフォームを B2B窓口と誤って対象づけてしまった**。
教育系サイトは「お問い合わせ」の大半が受験相談・資料請求であり、そのまま送ると届かない。

→ **この判別を機械化することが本タスク最大のレバー。** 判別ルールを作り、テストで固定する。

### 判別ルール（初版・実データで改訂していく）

**B2B窓口である可能性が高い signal:**
- URLに `corporate` `company` `business` `partner` `press` `media` `ir` `recruit`（採用は別部署だが法人窓口に近い）
- ページ内に「法人のお客様」「協業」「提携」「取材」「広報」「事業に関するお問い合わせ」
- フォームの必須項目に **会社名 / 部署 / 役職** がある
- 会社概要ページ（`/company` `/about`）からリンクされている

**受験生・保護者向けである強い signal（＝除外）:**
- 「資料請求」「体験授業」「無料相談」「入塾」「見学」「説明会」「受講」
- フォームの必須項目に **学年 / 志望校 / 学校名 / 保護者氏名 / お子様のお名前**
- URLに `contact/student` `soudan` `taiken` `shiryo` `entry`

**判定不能:**
- 単一の `/contact` しか無く、上記どちらの signal も出ない → **「判定不能」として記録し、送信対象に入れない**
  （C1: 分からないものを分かったことにしない）

### DoD（1社あたり）

各社について以下が埋まって初めて「検証済み1件」と数える:
```
org            正式社名
lane           上記1〜8のどれか
channel        'form' | 'email'
contact        フォームURL または メールアドレス
contactClass   'b2b' | 'consumer' | 'unknown'   ← unknown は送信対象外
evidence       そう判定した根拠（ページ内の文言 or 必須項目名）※実際に開いて確認したもの
verifiedAt     確認日
```
⚠️ **`evidence` が空のレコードを「検証済み」に数えない。** 推測でclassを付けない。

## 手順（1周回あたり20〜50社）

1. lane を1つ選び、母集団を列挙（WebSearch / 業界団体の会員名簿 / 既存の `data/outreach-queue.json` の未着手分）
2. 各社の連絡経路を**実際に開いて**判別ルールを適用し、上記スキーマで記録
3. `data/outreach-queue.json` に追記（既存スキーマ `id/org/lane/channel/contact/subject/body/status/sourceDoc` に
   `contactClass` / `evidence` / `verifiedAt` を追加する）
4. `contactClass='b2b'` のものだけ、提案文の下書きを作る
5. **メールは Gmail MCP で下書き設置まで。送信ボタンは👤。** フォームは Cowork で送信直前まで。

## ⛔ C7（絶対に破らない）

- **対外メールの送信は👤のみ。** `gmail.send` スコープは意図的に持っていない
- **フォーム送信も👤の確認を経る**（Coworkで直前まで自動化してよいが、送信ボタンは人間）
- **PIIを記録しない**（個人名・個人のメールアドレス。法人の代表窓口アドレスは可）

## kill_criteria

- `contactClass='b2b'` を100件積んで、送信後の**返信率が5%未満**（現在は17件中商談1＝5.9%）→ lane構成を見直す
- 特定 lane で20社連続 `unknown` → その lane は判別不能として一旦停止し、別 lane へ移る

## 計測

- 週次で `data/outreach-ledger.json` の status（awaiting / replied / meeting / declined）を集計
- **被リンク獲得数を別途数える**（契約にならなくても記事紹介・相互リンクは成果）
- ⚠️ 現状の実績: 接触32社 → 商談1件（3.1%）。**ただしこの外挿は「同じチャネルに送り続ける場合」にのみ成立する。**
  未接触チャネルを開けばこの率は無効になる（`ops/proposals/S13.md` §6-4 条件2）
