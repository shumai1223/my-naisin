## なぜこれが最優先なのか（測定の結論）

### 事実1: 新しい記録を作っても稼がない

```
直近7日  総クリック 1,910 / 露出URL 2,033本
  上位  1本(/hensachi)  601c = 31.5%
  上位  4本             976c = 51.1%
  上位100本            1,538c = 80.5%
  ★クリック0のURL     1,592本 = 全体の78%
```

**3,532URLのサイトで、実質稼いでいるのは100ページ。**
学校ページは1,797本で423クリック＝**1URLあたり0.24**。記録を足す作業は78%の側を増やす。

**この作業は新しいURLを1本も作らない。既存3,089枚の中身を冬に新鮮に保つ作業である。**

### 事実2: 冬のピークは倍率で決まる

```
「高校 倍率」の季節係数（8月=1.00・Trends実測5年262週）
  11月 2.41 → 12月 2.59 → 1月 12.17 → 2月 24.14
週解像度では 2/07 の週が年間最大
```

学校ページで**唯一CTRが機能している意図が倍率**（倍率1.17% / 偏差値0.59% / 内申・ボーダー0.00%）。

### 事実4: 1県ぶんの読解が重い

千葉のヘッダコメントより:
> 列は「募集定員(A)」「募集人員(B)」「志願者確定数(C)」「倍率(C/B)」の4本立て。
> **Aは名目定員、Bが実際に一般選抜で競われる枠**（千葉高・東葛飾高は併設型中高一貫校の
> 内部進学者定員をAから差し引いた数がB＝資料の注記1）。本データはBをquotaとして採用する。

47県すべて違う。埼玉は「入学許可予定者数(A)」、大阪は第2志望クロス集計あり。
**埼玉ではこの読解を誤って4件の転記ミスが発生し、グランドトータル検算で発見された。**

## 守ること

- ⚠️ **一致しないデータを合わせにいかない。** 差分は「未解明差分あり」として明示的に記録する
- ⚠️ **画像PDFの県は正直にスキップ台帳へ**（Y-0の「画像PDF県は正直にスキップ」原則）
- ⚠️ **相手サーバに負荷をかけない**（1県1日1回・間隔800ms以上・UAを名乗る・robots.txt尊重）
- ⚠️ **学校別偏差値・ボーダー推定は書かない**（Y-0憲法）
