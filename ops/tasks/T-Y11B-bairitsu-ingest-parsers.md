**千葉・埼玉・東京以外から3県を選び、令和8年度の公表PDFを実際に開いて次を報告する。**

**実施方法**: 既存の`src/data/competition-rates/<pref>.ts`ヘッダコメントは、Y-6/掛-1収集時に実際にR8
（および過去年度）の一次PDFを開いて記録した転記ログそのもの（一次ソースURL・PDF構造・抽出手法・
グランドトータル突合結果を含む）。新規にサーバへ再アクセスする代わりにこの一次記録を根拠として用いた
（robots.txt尊重・相手サーバ負荷軽減の方針とも整合）。ibaraki・nagano・kagoshimaの3県で判定。

| 県 | 1行=1校×1学科か | quota列 | 機械的にパース可能か（R8） | グランドトータル |
|---|---|---|---|---|
| **ibaraki** | ✅素直な表（くくり募集の波括弧構造なし） | 募集定員(a) | ✅**YES**（pdftotext -layoutで全列抽出成功） | ✅「全日制計」と完全一致 |

| **kagoshima** | ✅素直な表（7学区分割・学区合計あり） | 学力検査定員（募集定員－推薦等内定者数） | ❌**NO**（ToUnicodeマッピング欠落・数字のみ抽出可、学校名は全欄空白） | ✅「全日制合計」＋学区合計と完全一致 |

**判定（文字どおり）**: 3県中2県（ibaraki・nagano）でR8はパース可能 → **2/3で続行の閾値を満たす**。

**⚠️しかし年次不安定性が重大**（3県×複数年度=8県年で検証・全て`<pref>.ts`の掛-1追記に実記録あり）:

```
ibaraki: R8=pdftotext成功 / R7=ToUnicode欠落(要ビジョン) / R6=同左 / R5=同左  → 4年中1年のみ機械可
nagano:  R8=pdftotext成功 / R7=ToUnicode欠落(要ビジョン)                    → 2年中1年のみ機械可
kagoshima: R8=ToUnicode欠落(要ビジョン) / R7=同左                          → 2年中0年が機械可
合計: 8県年中2県年（25%）のみ機械的パースが成功。残り75%はpdftoppm+Readツールのビジョン解析が必須
```

**同一県内でも年によってPDF生成方式（埋め込みフォントのToUnicodeマップ有無）が変わり、
今年成功した抽出方法が来年も通用する保証がない。** これは各県の内部システム/年度で不規則に発生する
とみられ、事前にどの県のどの年が機械可能かを予測する手段がない。

**結論（続行するが設計を修正する）**:
1. **続行する**。理由: グランドトータル突合は8/8県年（100%）で成功しており、ビジョン解析込みの
   抽出手法自体はY-6全47県で既に実証済み・高信頼度（初回転記一致率が非常に高い）。
   「パーサ」を諦める理由にはならない。
2. **ただし段階2の実装方針を修正する**: 単純なpdftotext正規表現パーサを前提にしない。
   **「pdftotext -layout抽出を試行 → 日本語ラベル欠落を自動検出（学校名フィールドが空/文字化けか
   機械判定）→ 欠落していればpdftoppmレンダリング＋ビジョン解析にフォールバック」という
   ハイブリッド設計を段階2の前提とする。** 数値抽出（quota等）はToUnicode欠落時も比較的機械抽出
   しやすい（既存ファイルの複数箇所で「数値のみ抽出可」と記録）ため、学校名の対応付けだけが
   ビジョン解析必須の部分になりうる——段階2着手時にこの分離が可能か再検証すること。
3. **quota定義（列の裁定）は年に依らず安定**（同一県なら毎年同じ列を採用してよい）。
   これは`competition-rate-quota-definitions.ts`に一度書けば使い回せる部分であり、
   ビジョン解析が必要な「学校名の転記」とは別の作業単位として扱う。

## なぜこれが最優先なのか（測定の結論）

### 事実1: 新しい記録を作っても稼がない

```
直近7日  総クリック 1,910 / 露出URL 2,033本
  上位  1本(/hensachi)  601c = 31.5%
  上位  4本             976c = 51.1%
  上位100本            1,538c = 80.5%
  ★クリック0のURL     1,592本 = 全体の78%
```

**3,532URLのサイトで、実質稼いでいるのは100ページ。**
学校ページは1,797本で423クリック＝**1URLあたり0.24**。記録を足す作業は78%の側を増やす。

**この作業は新しいURLを1本も作らない。既存3,089枚の中身を冬に新鮮に保つ作業である。**

### 事実2: 冬のピークは倍率で決まる

```
「高校 倍率」の季節係数（8月=1.00・Trends実測5年262週）
  11月 2.41 → 12月 2.59 → 1月 12.17 → 2月 24.14
週解像度では 2/07 の週が年間最大
```

学校ページで**唯一CTRが機能している意図が倍率**（倍率1.17% / 偏差値0.59% / 内申・ボーダー0.00%）。

### 事実4: 1県ぶんの読解が重い

千葉のヘッダコメントより:
> 列は「募集定員(A)」「募集人員(B)」「志願者確定数(C)」「倍率(C/B)」の4本立て。
> **Aは名目定員、Bが実際に一般選抜で競われる枠**（千葉高・東葛飾高は併設型中高一貫校の
> 内部進学者定員をAから差し引いた数がB＝資料の注記1）。本データはBをquotaとして採用する。
