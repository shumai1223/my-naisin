## K1-1 KAKENから対象課題を引く

**KAKEN（科学研究費助成事業データベース・NII）は採択課題を公開しており、
研究代表者名・研究期間・課題番号・研究概要が索引されている。**

- [ ] **研究期間に2026年度（令和8年度）を含む**課題に絞る
      （期間が終わっている課題は予算が無い）
- [ ] キーワード: `高校入試` / `入学者選抜` / `教育格差` / `進路選択` / `高校統廃合` /
      `内申点` / `調査書` / `学校選択` あたりから始める。**実際にヒットした語を記録すること**
- [ ] 各課題について **研究代表者名・所属機関・課題番号・研究期間・研究概要** を取る
- [ ] ⚠️ Fableが例として挙げた `25K23216`（高校生の進路選択に対する高校統廃合実施の
      インパクトに関する教育社会学的研究・2025〜2027年度）が**実在するかをまず確認する**。
      実在しなければ検索条件から見直す

## K1-2 「この研究にうちのデータが使えるか」を1件ずつ判断する

**リストの長さではなく、当たりの濃さで決まる。**

- [ ] 研究概要を読み、**うちのどのデータが具体的にどう使えるか**を1件1行で書く
      （例: 「県別×年度別の定員・倍率が統廃合前後の比較に直接使える」）
- [ ] 使い道が書けない課題は**リストから外す**。数を作らない
- [ ] ⚠️ **50件のリストより、使い道が明確な10件のほうが強い**

## K1-3 送信文面を作る（送信は👤・9/23以降）

**「引用してください」ではなく「年度内に納品できます」に変える。**
これは8/27の商談で学んだ「質問の向きを反転させる」型と同じ。相手の予算消化の都合に乗る。

- [ ] 文面に入れるもの:
      - その先生の研究課題名を挙げ、**具体的にどのデータがどう使えるか**（K1-2の1行）
      - 提供できる形式（CSV/JSON・整形作業込み）
      - ⚠️**「1月中にご発注いただければ年度内に納品できます」と書くこと。**
        「3月31日まで」ではない。**多くの大学は年度末の発注締切が1月**で、
        3月を締切だと思って書くと、相手の実際の締切を2か月過ぎている
      - **見積書を出せること**（役務費・物品費として処理できる形）
- [ ] ⚠️ **金額を文面に書かない。** 「ご予算に合わせてお見積りします」に留める（価格はC7ゲート）
- [ ] ⚠️ **1通目の送信は👤のみ。** loopは下書きをGmailに設置するところまで
- [ ] ⚠️ **PIIを記録しない。** 個人名・所属はGmail下書きの中だけで、リポジトリに書かない。
      台帳には課題番号と「送信済み/未送信」だけを持つ
