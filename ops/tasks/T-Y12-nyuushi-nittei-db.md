# T-Y12 入試日程DB（47県×複数年度）

## 何が違うのか（`juken-schedule.ts`との違い）

`src/lib/juken-schedule.ts`は「県別・学校別の具体的な入試日程は検証不能」として、全国共通の
月レベルの目安のみを持つ設計にしていた。これはT-Y11B着手前は正しい判断だった。

T-Y11B（倍率パーサ）で47県の教育委員会公表資料を継続的に確認する体制ができたことで、
各県が別途公式サイトで公表している「入学者選抜の日程」（出願期間・学力検査日・合格発表日等）
も一次ソースとして収集できることが判明した（T-Y11Bタスクファイル「この作業が終わったら」§1）。
**前提が変わった。もう検証不能ではない。**

## なぜやるのか

Trends実測（[[fable5-fullaccel-backlog-2026-07]]内でT-Y11B着手時に引用済み）: 「高校入試 日程」
18.22 / 「出願期間」11.95。1月61 / 2月63 / 12月21のスコアで冬に集中する検索意図。
`/juken-schedule`は既に導線として存在するが、月レベルの一般論に留まり検索意図（「うちの県はいつ？」）
に直接応えていない。

## ★★ 着手前ゲート（2026-09-04実施・判定=続行）

47県中3県（ibaraki/chiba/osaka）でWebSearch+WebFetchにより実際に確認:

| 県 | 公式一次ソースページ | 日程の粒度 |
|---|---|---|
| 茨城 | `kyoiku.pref.ibaraki.jp/gakko/nyushi/highschool/schedule2026/` | 出願期間・学力検査日・合格発表日・第2次募集まで詳細記載 |
| 千葉 | `pref.chiba.lg.jp/kyouiku/shidou/nyuushi/koukou/r8/r8jissiyoko.html` | 実施要項ページに学力検査2/17-18・合格発表3/3 |
| 大阪 | `pref.osaka.lg.jp/o180040/kotogakko/gakuji-g3/r08_jisshiyoko.html` | 実施要項に学力検査3/11・合格発表3/19 |

3県とも「入学者選抜実施要項」または専用の日程ページという**構造化された一次ソース**を持つ。
ibarakiの学力検査日(2/26)・合格発表日(3/11)は、WebFetch直接取得と、独立した教育系メディア
記事（塾選ジャーナル・やる気アシスト等の複数媒体）の**両方**で一致を確認済み
（[[fable5-loop-protocol]]「総括表PDFのビジョン解析は…独立した二次情報源で突合」の教訓を
HTML一次ソースにも適用）。**続行してよいという判定。**

⚠️ ただし令和9年度（2027年度・来年の入試）分は多くの県でまだ未公表（ibarakiのschedule2026
URLは令和8年度分のみ）。**令和9年度分は例年の公表時期（県により異なるが概ね夏〜秋）を待つ必要が
あり、今すぐ全県分は取れない。** 令和8年度（今年度＝直近に終わった/これから終わる入試）分から
収集し、令和9年度分は各県の公表を確認できたタイミングで追記する（T-Y11Bの「速報→確定」と同型の
段階的収集）。
