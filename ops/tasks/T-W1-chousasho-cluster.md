## W1-1【最優先】「調査書点計算」で自サイトが4分裂している

直近7日の page×query 実測。**同じクエリを4ページで奪い合っている:**

```
調査書点計算 サイト   8表示 1クリック 位3.4  /tokyo/naishin
調査書点計算 サイト   4表示 0クリック 位7.8  /
調査書点計算 サイト   4表示 0クリック 位8.2  /tokyo/total-score
調査書点計算 サイト   2表示 0クリック 位3.0  /miyagi/naishin
```

**これは学校ページの校名クエリとは違う。** 校名クエリは「どのページが出ても答えを持っていない」
（Y-0の構造的天井）が、**調査書点はうちが答えを持っている**。総合得点エンジンが既にある。

- [ ] 「調査書点」が県ごとに何を指すか（東京の推薦入試の調査書点 / 埼玉の調査書点 等）を
      **既存の `total-score` の県別データと `prefecture-exam-systems-verified` の範囲で**整理する
- [ ] **どのページを「調査書点計算」の受け皿にするかを1つ決める**。候補は `/chousasho/hyoutei`
      （既存・調査書点と内申点の関係を扱っている）。決めたら他ページからそこへリンクを集める
- [ ] 受け皿ページの title/description を「調査書点」主語にする
- [ ] ⚠️ **県別ページの title は変えない。** `/tokyo/naishin` は位3.4で取れている。壊さないこと
- [ ] 変更前後で GSC を4週間追えるよう、**着手日の実測を記録してから**変更する
