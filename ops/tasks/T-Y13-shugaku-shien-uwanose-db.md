# T-Y13 高校生等就学支援金・都道府県独自「上乗せ」制度DB（47県×複数制度）

- 起票: 2026-09-15（👤指示・Discord運用セッション） / 実行主体: loop単独（対外送信・env・D1操作なし）
- 関連: [[card-5-private-highschool-recruiting]] のような温存タスクではない。制度データの転記のみで
  Y-0違反リスクは低い（学校別推定ではなく都道府県の公表制度の転記）

## なぜやるのか

`src/lib/education-cost/data.ts` の `SHUGAKU_SHIEN_TIERS`（59-81行目）は**国の基礎制度3区分のみ**を
実装済み。同ファイル79行目のコメント自身が「近年は所得制限の見直しや自治体独自の補助があり、
自治体ごとに要確認」と明記しているとおり、**都道府県が独自に上乗せする制度は現状ゼロ件・未収集**。

「進学費用は世帯年収と居住県で実際にいくら変わるか」という保護者の実質的な関心に、
国の3区分だけでは答えられない（例: 東京都と他県で私立高校進学者の実質自己負担は制度上
大きく異なりうるが、現状のサイトはその差を一切出せない）。

⚠️ **需要規模（検索ボリューム等）は未検証。** 着手前にTrends等で確認できるなら確認すること。
確認できないまま「保護者の関心が高い」と断定して着手しない（[[no-revenue-projections-guideline]]）。

## Y-0憲章の適用（据え置き・他のY系タスクと同一）

- **公表値のみを転記する。独自推定はしない**
- **1データ点1出典**（都道府県の私学課・教育委員会が公表するページ／PDFのURL必須）
- 制度は年度で改定されるため `fiscalYear` ごとに別レコードとして持つ
  （`competition-rate.ts` / `exam-schedule.ts` と同型の設計）
- **確認できない県は `unknown` として明示的に記録する。空欄で放置しない・推測で埋めない**
- 47県揃わなくてよい。「制度なし」を確認できた県は「制度なし確認済み」として区別する
  （`unknown` と「調べた結果、無いと分かった」は別の状態として扱う）

## 対象とする制度（3種・県により実施有無が異なるので一律の型に無理に当てはめない）

1. 都道府県版・私立高校等授業料軽減助成金（国の就学支援金に上乗せする形の独自助成）
2. 高校生等奨学給付金（非課税世帯向け・国の基準額に都道府県が上乗せしている場合がある）
3. その他、県単独の入学金・教材費補助等（制度名・要件が県により大きく異なる）
