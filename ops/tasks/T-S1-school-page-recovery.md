## ① sitemap漏れ333校 — 原因を訂正（2026-08-28夜・診断スクリプト実装で判明）

⚠️ **起票時点の診断は誤りだった。** `buildSchoolPageDataForPrefecture` の `skipped`（学校名突合失敗）が
原因だと書いたが、`scripts/check-school-name-gaps.mjs` を実装して実測したところ、**333校の内訳の
大半（290校・87%）は名前突合の失敗ではなく、そもそも今年度の倍率データ(`competition-rates/*.ts`)
に該当校のレコードが1件も存在しない**ことが原因だった。`skipped`（エイリアスで救済できる名前
不一致）はわずか43校（13%）に過ぎない。

```
学校マスタ 3,422校
  └ 今年度倍率データに何らかの形でレコードがある: 3,132校（unique school name数と完全一致）
       ├ 名前が完全一致してページ生成された: 3,089校 = sitemap実測と一致
       └ 名前が一致せずskippedされた: 43校 ← エイリアスで救済可能
  └ 今年度倍率データにレコード自体が無い: 290校 ← エイリアスでは救済できない別問題
```

**エイリアス追加は「43件のうち一部」しか解決しない。** 290校がなぜ倍率データを持たないかを

#### 290校問題の続報: 大半は「バグ」ではなく元々の設計どおりのスコープ除外だった可能性が高い

hyogoの内訳37校（skipped3件+データなし34件）を実際に洗い出したところ、**`competition-rates/hyogo.ts`
のファイル冒頭コメントに、この倍率データが「全日制127校」に意図的に限定されており、定時制19校
（県立15校・市立4校）は「東京都・神奈川県・千葉県・埼玉県・福岡県と同じ理由でスコープ外」と
明記されていた**（東京・神奈川・千葉・埼玉・福岡でも同型の`定時制課程は他県と同じ理由でスコープ外`
という記述を確認済み・grep実測）。つまり**このsitemap漏れの一部は、そもそも「全日制の入試倍率」
という商品の性質上、定時制専門校・定時制のみの課程には該当データが存在しないのが正しい状態**であり、
「収集モレ」ではなく設計どおりの可能性が高い。

⚠️ **ただし全部が定時制起因と確定したわけではない。** hyogoの「データなし34校」のうち、
コメントが言及する定時制19校（県立15+市立4）とは数が一致しない（34≠19）。学校マスタに
課程種別(全日制/定時制)を示すフィールドが無いため、機械的な突合はできず、**残る差分15校
（統合校・改編校・単位制多部制校等の可能性）は個別にWebSearchで実在の課程を確認しないと
「定時制だから除外は正しい」のか「本当に収集モレ」なのか判別できない**。

**次にやるべきこと（優先順位）**:
1. **290校を「収集除外が正しい定時制系」と「未調査の残差」に分ける前に、まず学校ページ自体が
   定時制専門校向けに何を表示すべきか（そもそもページ生成の対象にすべきか）を再考する**。
   全日制の倍率が無い学校に「倍率データなし」のページを作ること自体が目的に適うか、
   Y-0の「薄いページを作らない」原則との整合を先に判断すべき。
2. 上記1の判断が出るまで、**残り34校×47県=290校規模の個別WebSearch調査には着手しない**
   （多くが実は「正しく除外されている」可能性が高い状態で、大量の調査コストをかける前に
   スコープの妥当性を先に固めるべき）。
3. 判断のヒントとして、`competition-rates/*.ts`の各県コメントに「定時制」「通信制」「対象外」
   等のスコープ除外注記がある県は多い（osaka「定時制・通信制・特別選抜等はこの資料の対象外」等）。
   これらの県では290校の相当割合が意図的除外である可能性が高く、逆にこの注記が無い県で

## ③ 断片URL対策は **やらない**（2026-08-28に取り下げ）

当初「断片URLが15,516表示でクリック0＝サイト全体の15%が死んでいる」と診断したが、
**page×query の2次元で実測したところ誤りだった。**

```
断片行 1,880行 / 27,501表示
  ├ 本体にも同じクエリの行がある: 1,880行 27,501表示 = 100%
  │   → その本体行が獲得したクリック: 856
  └ 断片にしか無い:                     0行 0表示 = 0%
```

**GSCが同じSERP出現を2行に分けて数えているだけで、失っているクリックは無い。**

さらに、ブログのCTRについては既に👤の裁定がある:
> 「ブログの漏れはAI Overviewで回収不能→**触らない（本人合意）**」

→ **この件は再オープンしない。** 触らない。
