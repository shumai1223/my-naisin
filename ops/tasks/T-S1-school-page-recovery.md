## ① sitemap漏れ333校 — 原因は特定済み

`src/lib/school-page-data.ts` の `buildSchoolPageDataForPrefecture` が、
**倍率データの学校名を学校マスタにマッチできなかった学校を `skipped` として落としている。**

```
if (match.reason !== 'matched' || !match.matchedCode || !match.matchedFullName) {
  skipped.push({ schoolName, reason: match.reason === 'ambiguous' ? 'ambiguous' : 'no-match' });
  continue;
}
```

→ ページが生成されない → sitemapにも載らない → 永久に露出しない。

**45/47県で発生している（系統的）。**

| 県 | 漏れ | 率 |
|---|---|---|
| **hyogo** | **48/161** | **30%** |
| **fukushima** | **25/75** | **33%** |
| osaka | 23/148 | 16% |
| tokyo | 20/187 | 11% |
| niigata | 14/84 | 17% |
| **ehime** | **14/57** | **25%** |
| okayama | 12/63 | 19% |
| hokkaido | 12/217 | 6% |
| miyagi | 10/78 | 13% |
| kanagawa | 10/148 | 7% |

（以下 yamaguchi 9・kyoto 9・chiba 9・saitama 7・nagano 7・ibaraki 7・hiroshima 7・fukuoka 7・aichi 7・wakayama 6 …）

### やること

1. **`skipped` の中身を県ごとにダンプする診断スクリプトを作る**
   （`scripts/check-school-name-gaps.mjs` 等）。
   出力は「県 / 倍率データ側の学校名 / reason(no-match|ambiguous) / マスタ側の近い候補」。
2. **`SCHOOL_NAME_ALIASES_BY_PREFECTURE` にエイリアスを追加**して回収する。
   miyagi では既にこの方式で解決した実績がある（2026-08-02 commit）。
3. **漏れの多い県から順に処理する**: hyogo(48) → fukushima(25) → osaka(23) → tokyo(20)。
   **上位10県で222校＝全漏れの67%が回収できる。**

### ⚠️ Y-0の一線（これを破ったら意味がない）

- **エイリアスは「この教委の学校名＝この文科省の学校コード」という断定である。**
  推測で結びつけない。**`ambiguous`（複数候補）は解決できるまで skipped のまま残す。**
- 分校・統廃合・学科改編で**実体が違うもの**を無理に繋がない。
- 1件ずつ、**なぜそのエイリアスが正しいと言えるか**をコメントに残す。
- 回収できなかった学校は、**「回収できなかった」と台帳に正直に記録する**（沈黙させない）。

## ② sitemapにあるが表示ゼロ 1,207枚

sitemapに載っているのに、GSCで1度も表示されていない。
👤がGSCで確認した「**検出 — 未登録 1,036ページ**」とほぼ一致する。

### 県別の露出率（極端に偏っている）

| 良い県 | 露出/母数 | | 死んでいる県 | 露出/母数 |
|---|---|---|---|---|
| tochigi | 56/60 (93%) | | **hokkaido** | **6/217 (3%)** |
| fukuoka | 95/103 (92%) | | **osaka** | **14/148 (9%)** |
| aichi | 149/163 (91%) | | **chiba** | **8/128 (6%)** |
| gifu | 60/66 (91%) | | **ibaraki** | **2/92 (2%)** |
| | | | **hiroshima** | **8/90 (9%)** |

⚠️ **ibaraki は平均順位4.8と良いのに、92校中2校しか露出していない。**
順位の問題ではなく、**そもそもインデックスされていない**。

### 仮説（loopが検証すること）

1. **クロール待ち**: 26県が 2026-08-09 に一括解禁された。2.5週間しか経っていない
   → 検証方法: **解禁waveごとに露出率を集計する**。wave1(08-01)が高くwave5(08-09)が低いなら、待てば解決する
2. **内部リンクが薄い**: 県トップから個別校へのリンクが十分にあるか。
   3,000枚を1階層下にぶら下げているなら、クロール予算が回らない
3. **ページの内容が薄い**: 倍率データが1年度分しかない学校は、Googleが価値なしと判断している可能性
   → 検証方法: **露出のある学校とない学校で、history（多年度データ）の有無に差があるか**を集計する

### やること

- [ ] **まず仮説1を検証する**（waveごとの露出率）。これで「待てば解決」かどうかが分かる。**ここを飛ばして施策を打たない**
- [ ] 仮説3を集計で検証する（データ量と露出の相関）
- [ ] 内部リンクの実態を確認する（県トップ→個別校の導線が何階層か）
- [ ] **結論が出るまで、大きな施策を打たない。** 原因が分からないまま3,000枚をいじると壊す

### ⚠️ やってはいけないこと

- ❌ sitemapを分割する・優先度を弄る等の小手先（原因が分からないうちは効果が測れない）
- ❌ 露出が無いことを理由にページを削除する
- ❌ 内容の薄いページを水増しする（Y-0・scaled content）

## ③ 断片URL対策は **やらない**（2026-08-28に取り下げ）

当初「断片URLが15,516表示でクリック0＝サイト全体の15%が死んでいる」と診断したが、
**page×query の2次元で実測したところ誤りだった。**

```
断片行 1,880行 / 27,501表示
  ├ 本体にも同じクエリの行がある: 1,880行 27,501表示 = 100%
  │   → その本体行が獲得したクリック: 856
  └ 断片にしか無い:                     0行 0表示 = 0%
```

**GSCが同じSERP出現を2行に分けて数えているだけで、失っているクリックは無い。**

さらに、ブログのCTRについては既に👤の裁定がある:
> 「ブログの漏れはAI Overviewで回収不能→**触らない（本人合意）**」

→ **この件は再オープンしない。** 触らない。
