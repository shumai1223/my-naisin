## やること

### C3-1 ベネッセ商談の振り返りを言語化して型にする

Gmail の当該スレッド（送信済み 2026-07-22）を読み、以下を1ファイルに落とす。

- 相手が言った**課題の言葉そのもの**（言い換えない。営業文面はこの言葉を使う）
- こちらが答えられなかった質問／詰まった箇所
- 次に同じ質問が来たときの答え

⚠️ **個人名・所属は書かない（PII・C7）。** 「大手通信教育の担当者」等の粒度にする。

### C3-2 想定問答集を作る（B2Bライセンス商談用）

最低この10問には即答できる状態にする。**答えは実データで裏を取る（憶測を書かない）。**

1. データはどこから取っているのか（→ 47都道府県教委の公表資料。一次ソースURLを即出せるか）
2. 更新はどうなるのか（→ 年次更新の体制。T-A1 多年度化の実績）
3. 精度はどう担保しているのか（→ 不変条件テスト・jest件数・Y-0憲法）
4. 中学生が運営しているが継続性は（→ 契約主体は親権者名義。ここは正直に答える）
5. 独占はできるのか
6. 価格の根拠は（→ 自社で47県分を作る場合の工数と比較）
7. 使える形式は（→ REST API / MCP / CSV / JSON。`/developers` を見せる）
8. 商用利用の範囲は（→ 利用規約・再配布の可否）
9. 他社の導入実績は（→ **無い。無いと正直に言う。代わりに公開APIの稼働実績を出す**）
10. 試せるのか（→ 無料枠・APIキー即発行）

### C3-0 【確定済み・毎回この形でやる】保護者同席の運用

2026-08-14 の旺文社案件で確定させた型。**以後の商談は全部これで回す。**

**前提**: 相手が保護者同席を求める理由は、商談内容に親を参加させたいからではなく、
**未成年と直接取引することの法的リスク（民法5条・未成年者契約の取消権）を避けたいから**。
→ **必要なのは「1時間の同席」ではなく「保護者が把握し同意している」という事実。** ここは分解できる。

| | やり方 |
|---|---|
| **接続** | **👤のPC1台の前に、冒頭だけ保護者が横に座る。** 別ログイン・アプリ導入は不要（保護者の負担を最小化する。「1時間空けて」ではなく「その部屋に来て座るだけ」にする） |
| **カメラ** | ON（顔を見せることが目的） |
| **所要** | **30分で提案する。** 1時間だと双方が構える。盛り上がれば延ばせばよい |
| **保護者の発言** | **台本を渡す**（下記）。忙しい人に「何か喋って」は最大の負担 |
| **退出** | **黙って抜けない。「では私はここで失礼します」と口に出してから抜ける** |
| **記録** | `scripts/meeting-copilot` の文字起こしを保護者へ共有。**冒頭に「メモにAIツールを使っています」と一言断る** |

**保護者の台本（30秒・これをそのまま渡す）**:

> はじめまして、〇〇の母でございます。本日はお時間をいただきありがとうございます。
> **息子がこのような活動をしていることは把握しており、私も応援しております。**
> 技術的な内容は本人の方が詳しいので、この後は本人からご説明させていただきます。
> **契約などのお話に進む場合は、改めて私がご対応いたします**ので、その際はよろしくお願いいたします。
> それでは、私はここで失礼いたします。

**明示的に退出宣言をさせる理由（ここが肝）**:
1. **相手が本題に入れる。** 画面外に親がいるかもしれない状態だと、相手は気を遣って踏み込めない
2. **相手の懸念が完全に消える。** 「契約の話になれば私が出ます」を**親の口から**言ってもらうことが、
   メールに書くより効く

**日程の取り方**: 候補が来てから保護者に聞くと往復が増える。**先に保護者から2〜3枠もらっておく。**
- **8月中は日中が取れる**（学校が夏季休業中）。相手が一般企業（9〜18時）の場合、ここが最良
- 9月以降は平日18時以降か土日に限定される
- **9/08〜9/22は不可**（ユタ）

### C3-5 【追加】**こちらから聞く質問を20問**用意する（沈黙対策・主導権の確保）

👤の不安:

> 「相手ペースにならずに、沈黙を作らない商談をするには、慣れとスキルを習得するしかない？」

**8割は設計で解決する。** 沈黙が怖いのは「次に言うことが無い」からで、材料があれば沈黙は
「相手が考えている時間」に変わる。**相手ペースになるのは、質問に答え続けるから。**

→ **答えたら必ず質問を返す**というルールを回すために、**こちらから聞く20問**を紙に用意する。
   使わなくてよい。**あることが安心を作る。**

20問の内訳（この配分で作る）:

| 区分 | 数 | 狙い |
|---|---|---|
| **相手の現状**（いま内申点をどう扱っているか・誰が作っているか・何時間かかっているか） | 6問 | **課題を相手の言葉で言わせる**。営業文面はこの言葉を使う |
| **次の商品の要件**（★今季いちばん価値がある） | 5問 | 例:「これが御社の管理画面に入っていたら使いますか」「教室の先生が使うとしたら何が要りますか」→ **FY2028の塾SaaSの仕様がここで決まる** |
| 導入の障壁（決裁者は誰か・予算の時期・情シスの審査） | 5問 | **商談を次に進めるための情報**。ここを聞かないと「検討します」で終わる |
| 断られたときに聞くこと | 4問 | **理由を必ず取る**。価格が理由か、文面が理由か、時期が理由かで次の打ち手が変わる |

**冒頭の型も1行で決めておく**: 「本日は御社の◯◯について伺いたくて、お時間をいただきました」
→ **アジェンダを先に出すだけで場の主導権が取れる。**

**DoD**: 20問が1枚に収まっている。`meeting-copilot` の画面から**ワンクリックで出せる**。
商談後、実際に使った質問と相手の答えを追記して育てる（1回目より2回目が強くなる）。

### C3-4 稟議に出せる1枚を作る

相手の担当者が社内で使う紙。**商談の場で渡すのではなく、商談前にメールに添える。**
これがあると「持ち帰って検討します」で消えない。

- 何のデータか／どこが一次ソースか／更新体制／価格／導入方法／試用方法
- **A4 1枚**。これ以上長くしない
