## API1-3 価格の梯子を壊れていない形に直す

**現状の不整合:**
```
free  15回/分  月10,000  ¥0
pro  600回/分  月10,000  ¥9,800/月   ← 月次クォータが同じ
pro  audience: '個人開発者・社内利用・検証（非商用）'  ← 有料なのに非商用の記述
```

👤裁定:
- [ ] `free.monthlyQuota` を 10,000 → **5,000**
- [ ] `pro.monthlyQuota` を 10,000 → **100,000**
- [ ] `pro.audience` から「（非商用）」を削除する
      （`anonymous` / `free` が `commercialUse: true` なのに有料が非商用という記述は誤り）
- [ ] `/developers` の表示を合わせる
