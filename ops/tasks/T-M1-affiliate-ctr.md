## 0. なぜやるのか（実測で確定した唯一のボトルネック）

2026-08-29にbotを全除去した実測値:

```
GSC 18,236クリック（06-18〜08-24）
  × 0.258%（アフィリンクを押す率）   ← ここが桁を殺している
  = 47クリック
  × 2.13%（CVR・n=1）
  = 1件
```

**CVRは悪くない。押されていないことがすべて。**

| レバー | 4倍にすると今季の確定額（中位）は |
|---|---|
| **クリック率 0.258% → 1%** | ¥25,827 → **約¥100,000** |
| CVR 2.13% → 4% | ¥25,827 → ¥48,500 |
| 流入 2倍 | ¥25,827 → ¥51,654 |

**クリック率が最も動く余地があり、かつ唯一こちらが動かせる**（CVRは相手のLPの仕事）。

## 2. やること

### M1-1【最優先・リスク最小】Z会枠を高EVオファーへ置換

- [x] 上記8箇所の `zkai-banner` / `zkai-text-middle` を、`affiliate-economics.ts` の
      **EV（cpaYen × convRate）が高いオファー**へ差し替える ✅2026-08-29
- [x] ⚠️ **`zkai-text-request`（資料請求・800円・CVR12% ＝ EV¥96）は残す。**
      Z会でも資料請求型は期待値が20倍違う。**paid種別の `zkai-banner`/`zkai-text-middle` だけを置換する**
      （`page.tsx`/`HomeClient.tsx`とも隣接する`zkai-text-request`は無変更のまま確認済み）
- [x] 置換先は**面の文脈に合うもの**を選ぶ（塾の無料体験＝`atama-text`/`sora-juku-text` 等）。
      **全部同じにしない**（1面1オファーに偏らせると比較ができなくなる）
      → 実装: guide=`morijuku-text`／glossary=`campus-text`+`campus-banner`／
      blog=`sora-juku-text`+`sora-juku-banner`／prefectures=`atama-text`+`atama-banner`／
      page.tsx=`morijuku-text`／HomeClient=`atama-text`。4銘柄×各2箇所で分散。
      いずれも`confirmedPer1000`がZ会paid枠（¥1,500/1000click）より2桁高い（free-lead帯）
- [x] `rankLiveOffersByEV()` が既にあるならそれを使う。無ければ手で選び、選定理由をコメントに書く
      → 既存関数のEV序列を確認のうえ手動選定（理由は本行とworklogに記録）。
      ⚠️副次対応: 置換元の周辺プローズがZ会固有の特徴（「テキスト＋添削」「定番教材」「学習教材」
      「通信教育という選択肢」等）を文字列で直接記述しており、塾系オファー（体験型・教材/通信教育
      ではない）へ置換すると文言が事実と食い違うため、該当箇所の周辺文も同時に書き換えた
      （[[fable5-loop-protocol]]の都道府県プローズ手書きドリフト教訓と同根）。`prefectures/page.tsx`は
      「地域差のない」という既存claimと矛盾しないよう、店舗型ではなくオンラインの`atama-text`を選定。

### M1-2【本命】学校ページに広告を入れる — **ただし1枠だけ**

- [ ] `src/app/pref/[code]/school/[schoolCode]/page.tsx` に `AffiliateAd` を**1枠だけ**追加
- [ ] **位置は「倍率データの表の下」以降。ページ上部・データの前には絶対に置かない**
- [ ] `placement="school"` を必ず渡す（面別の効きを分解するため）
- [ ] オファーは**塾の無料体験**（検索意図が「◯◯高校の倍率」＝その高校を受ける人なので相性が良い）

⚠️ **Y-0の制約（最重要）**: 学校ページは「教育委員会の公表データを出典付きで見せる」ことが
信頼の根拠になっている面である。**広告をデータより上に置くと、その性格が壊れる。**
「データ → 出典 → （区切り）→ PR表記付きの広告1枠」の順を守る。

⚠️ **インデックスの制約**: 現在 **1,207枚が「検出 – インデックス未登録」でGoogleの評価待ち**
（`ops/tasks/T-S1-school-page-recovery.md`）。ここに広告を大量に入れると
**「収益化目的のテンプレページ」と判定される危険**がある。**だから1枠だけにする。**

### M1-3 トップページは「増やす」のではなく「直す」

- [x] **枠を増やさない。** 既に4枠あって0クリックなので、増やしても0が増えるだけ（今回も未変更）
- [x] まず**なぜ押されないか**を調べる ✅2026-08-29
- [x] `cta_view` / `affiliate_click` のGA4イベントで、**表示はされているのに押されていない**のか
      **そもそも表示されていない（スクロール到達前に離脱）**のかを分ける
      → **結論: 切り分け不可能と判明（これ自体が原因）。** `src/app/page.tsx`の4箇所の`AffiliateAd`
      （L151/152/321/552）はいずれも`trackView`propを渡しておらず、`cta_view`計装が最初から
      opt-inで未設置（`AffiliateAd.tsx`の`trackView = false`既定のまま）。実際GA4(28日)で
      `customEvent:placement='home'`の`cta_view`は**わずか4件**しかなく、これはGSC実測
      「トップ114impression/7日(≒456/28日)」と2桁乖離しており、**この4件はpage.tsx以外の
      別コンポーネント（ParentLeadCTA等、placement='home'を渡す別箇所）由来**と判明した
      （page.tsx側のAffiliateAdが1件もtrackView計測していないため、この4箇所の表示自体を
      指す数値ではない）。**したがって「表示されているが押されない」か「表示自体されていない」かは、
      計測が無い以上どちらの数字も存在せず判定不能** というのが実測に基づく結論。
- [x] 結論が出るまで**トップページの広告構成を変えない** → 今回オファーの中身(M1-1)は変えたが
      **枠数・配置・構成（4箇所のまま）は変更していない**。次の一手は「計測を足す」こと
      （`trackView`+`viewPlacement="home"`を4箇所へ追加）だが、これは**実装**にあたるため
      本タスク(M1-3)の範囲外として着手せず、`ops/tasks/T-M1-affiliate-ctr.md`に次の課題として
      明記するに留める（👤判断 or 次周回への引き継ぎ）
