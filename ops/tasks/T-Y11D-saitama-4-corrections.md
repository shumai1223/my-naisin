## 訂正する4件（`src/data/competition-rates/saitama.ts` の令和8年度ブロック）

### ① 大宮科学技術・電気工学科 — `quota: 39` → `40`

**根拠は既存データの自己矛盾。** 格納されている `finalRate: 0.58` は quota=40 でしか出ない。

```
23 ÷ 39 = 0.5897…  → 四捨五入 0.59   ✕ 格納値0.58と不一致
23 ÷ 40 = 0.575     → 四捨五入 0.58   ○ 格納値と一致
```

PDF原本も40。**倍率と定員のどちらかが誤っており、PDFが定員=40を支持している。**

### ② 三郷工業技術・電気科 — `quota: 40` → `39`

**根拠は年次の一貫性とPDFの印字倍率。**

```
R5=39  R6=39  R7=39  R8=40   ← R8だけ40
PDF原本の印字倍率 0.82 = 32÷39   （格納値は 0.8 = 32÷40）
```

⚠️ このレコードは**既存データ内では自己整合している**（40と0.8が整合）。
つまり `quota` と `finalRate` の**両方**を直す必要がある。`finalRate: 0.8` → `0.82`。

### ③ 越谷総合技術・食物デザイン科 — 学科名 → `食物調理科`

```
R5 / R6 / R7 いずれも「食物調理科」。R8だけ「食物デザイン科」
直前行が同校の「服飾デザイン科」＝コピペ汚染
PDF原本は「食物調理科」
```

数値（quota 40・志願42・倍率1.05）は変更しない。**学科名のみ**。

### ④ 外国語科の学校名 — `越谷北` → `越谷南`

**根拠は年次を並べたときの学科構成。**

```
R7   越谷北 = 普通科・理数科          越谷南 = 普通科・外国語科
R8   越谷北 = 普通科・理数科・外国語科   越谷南 = 普通科のみ   ← R8だけ外国語科が北に移動
R5   越谷南 = 外国語科
PDF原本（既存データと同一URL）= 越谷南
```

**外国語科が2つの高校の間を年ごとに行き来することはない。** 越谷北=理数科、越谷南=外国語科が
安定した学校特性であり、R8のレコードだけが誤っている。

⚠️ **`saitama.ts` 冒頭コメント（L72付近）の記述も同時に訂正すること。**
現在「外国語科は『越谷南』（R7）↔『越谷北』（R8）のように学校間で開設が入れ替わる」と
書かれているが、これが誤りの発生源である。この一文を削除し、
「越谷南=外国語科／越谷北=理数科で年次を通じて安定」に置き換える。
