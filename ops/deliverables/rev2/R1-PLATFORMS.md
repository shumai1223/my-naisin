# R1 出品先の調査(一次資料): ココナラ・クラウドワークス・ランサーズ

- 調べた日: 2026-09-26
- 方法: 各社の利用規約・ガイドラインを **WebFetch** で読んだ(curl は使っていない)。WebFetch は要約モデルを通すため、**年齢条件と手数料は同じページに2回、聞き方を変えて問い合わせ、答えが一致したものだけを「確認済み」**とした。引用は WebFetch が返した条文をそのまま写したもの(改行・全角半角は原文と違う可能性がある)。
- 読めなかった項目は「未確認」と書いた(推測で埋めていない)。
- ⚠️ 規約は変わる。登録の直前に、下の URL を人が自分の目で読み直すこと。

**結論(事実の範囲)**: 読めた2社(クラウドワークス・ランサーズ)は、どちらも**本人が18歳以上であることが会員登録の条件**で、未成年が保護者の同意で登録できるという条文は無かった。ココナラは規約のページに到達できず、何も確認できていない。

**保護者名義で登録する場合について**: 規約には「登録した本人以外が作業してはいけない」とはっきり書いた条文は見当たらなかった。一方で、**アカウントを第三者に利用させることは2社とも禁止**している(下の引用)。「保護者名義で登録し、実際の作業や依頼者とのやり取りを中学生本人が行う」形がこれに当たるかどうかは、**規約の文面からは判断できない**。登録前に各社の問い合わせ窓口に、この形がよいかを文章で確認することを勧める(判断は👤と保護者)。

## クラウドワークス

- 利用規約: https://crowdworks.jp/pages/agreement.html (2026-09-26 取得)

### ① 未成年
- 第4条(会員登録)第4項第1号: 「**満18歳以上であること**」
- 2回目の問い合わせ(第4条の全文と「未成年」「法定代理人」「親権者」を含む文を列挙させた)の答え: 「第4条には『未成年』『法定代理人』『親権者』の語は実際に含まれていません」「年齢要件は第4条第4項(1)の『満18歳以上であること』のみ」 → **2回一致**
- アカウントの第三者利用(関係しそうな条文):
  - 第20条第2項: 「会員は、登録したID及びパスワードについて、第三者による利用や第三者への貸与・譲渡等の行為を行ってはならないものとします。」
  - 第22条: 「利用者は、本利用規約に基づく権利、義務及び本利用規約に基づき成立する契約上の地位の全部又は一部について、これを第三者に譲渡、質入れ、その他の方法により処分してはならないものとします。」

### ② AIの表示ルール
- 利用規約の全文に「AI」「人工知能」「自動生成」の語を含む文は無い(WebFetch の答え)。規約の本文から他の規程・ガイドラインへのリンクも無かった。
- ガイドラインらしきURL(`/pages/guideline.html`・`/pages/guidelines.html`)は 404。**AIに関する個別ルールの有無は未確認**。

### ③ 手数料
- 第9条第1項第1号(プロジェクト形式)の料率。1回目: 「各取引の報酬額で20万円を超える部分については報酬額の5％、10万円超20万円以下の部分については報酬額の10％、報酬額が10万円以下の部分については報酬額の20％」
- 2回目(10万円以下の部分の料率と消費税の扱いを聞いた)の答え: 10万円以下の部分 20%・10万円超20万円以下 10%・20万円超 5%・「消費税別・1円未満切り捨て」 → **2回一致**
- 第17条第4項: 「ワーカーに対する弊社の振込手数料については、ワーカーが負担するものとします。」(振込手数料の額は**未確認**)
- タスク形式の料率は2回目の答えに「時期により20%または無料」とあったが、原文の引用は取れていないので**未確認**扱い。

## ランサーズ

- 利用規約: https://www.lancers.jp/help/terms (2026-09-26 取得。`https://www.lancers.jp/terms` は 404)

### ① 未成年
- 第4条(会員資格)第1項: 「本サイトへの会員登録の条件は以下のとおりとします。1.**満18才以上であること** 2.日本語を正確に理解し、ビジネスレベルでの日本語の読み書きが出来ること 3.本規約に同意すること …」
- 2回目の問い合わせでも「第4条に『未成年』『法定代理人』『親権者』の記載はありません。『18』を含む文は『満18才以上であること』」 → **2回一致**

  - 第30条第1項: 「会員資格・ログイン情報を第三者に利用・譲渡・売買・貸与、その他形態を問わず処分することはできません。」
  - 第30条第2項: 「会員ID及びパスワードを利用して行われたあらゆる行為は、第三者が会員本人の同意なく行った場合や不正に使用した場合であっても、会員IDを保有している会員自身による行為とみなし、その責任を負うことに同意するものとします。」
