## 1. 誰が「送信者」か
法2条2号: 「営利を目的とする団体及び営業を営む場合における個人」が、自己又は他人の営業の広告・宣伝のために送る電子メールが「特定電子メール」。
→ 広告収入のあるサイト運営者が塾へ枠を売り込むメールは**対象になる**と考えて運用する。

## 2. 誰に送ってよいか(法3条1項・施行規則3条)
原則、事前に同意した者にしか送れない(オプトイン)。ただし次は例外で送れる:
- **自己の電子メールアドレスを、インターネットで公衆が閲覧できる状態に置いている団体・営業を営む個人**(法3条1項4号)
  - ⚠️ **ただし「特定電子メールの送信をしないように求める旨の文言」を、そのアドレスと併せて公表している場合は例外にならない**(規則3条ただし書) → **送らない**
- 取引関係にある者(1項3号)。今回は該当しない

### 送る相手の基準(TARGETS.csv の「営業お断り表記の有無」列の判定ルール)
| 判定 | 内容 |
|---|---|
| ✅送る | 塾のサイトに、**事業用の問い合わせ先**として公開されているメールアドレスがある。かつ営業・広告・勧誘お断りの記載がどこにも無い |
| ❌送らない | サイト・フォームに「営業・広告・勧誘・セールスのメールはお断り」等の記載がある |
| ❌送らない | 個人の講師の私的アドレス／SNSのDM／アドレスが公開されていない(推測で作らない) |
| ❌送らない | 「入塾のお問い合わせ専用」等、用途が入塾相談に限定されたアドレス(営業に使うのは趣旨に反する) |
| 🟡フォーム | 問い合わせフォームしか無い塾 → Coworkのフォーム指示へ。**フォームに「営業目的の利用禁止」と書いてあれば送らない** |
- 1回目の後、**受信拒否の返信・連絡が来た相手には二度と送らない**(法3条3項。TARGETS.csv の状態に `拒否` を記録して二度と下書きを作らない)

## 3. メールに必ず表示すること(法4条・施行規則7条・9条)
特定電子メールには、受信者の画面に次を**正しく**表示する:
1. **送信者(責任のある者)の氏名または名称**(正式なもの)
2. **受信拒否(今後送らないでほしい)の連絡先メールアドレス**(=送信に使ったアドレスで返信すれば拒否できる場合は、その旨。規則7条1項2号・9条1号)
3. 「受信拒否は、上のアドレス宛にメールを送ることで通知できる」旨
4. **送信者の住所**(規則9条2号)
5. **苦情・問い合わせを受け付けられる電話番号、メールアドレス、またはフォームのURL**(規則9条3号。電話番号は必須ではなく、メールアドレスでもよい)
- 表示は本文中の、受信者が容易に分かる場所に置く。本文と同じ文字コードで(通常のテキストなら問題なし)
- 送信者情報(From)を偽らない(法5条)

## 4. ⚠️ 「住所」の扱い＝👤への質問(質問ノートに記載済み)
規則9条2号は**送信者の住所**の表示を求めている。運営者は中学生で、自宅住所をメールに書くことは避けたい(リポジトリにも書かない)。案:
- **案A: フォーム営業に一本化する**。特定電子メール法の対象は「電子メール」(法2条1号・総務省令で定める通信方式)で、Webフォームからの送信は通常対象外。住所表示の問題を避けられる。ただし数が減る(公開メールアドレスが主な窓口の塾が多い)。フォームの「営業禁止」記載は必ず守る
- **案B: 送信者の住所として使える「事業用の住所」を用意する**(親権者の事業所・バーチャルオフィス等)。契約名義人が親権者なので親権者側で決められる。私書箱が「住所」として認められるかは一次資料で確認できていない。
- **案C: 住所を書かずに送る**→ 法4条違反(規則9条2号)になり得るため**採らない**
- loopは住所を知らないため、メール末尾は下記のとおり**住所欄を `【住所: 👤が記入】` の空欄**にして下書きを作る。空欄のまま送信ボタンを押さないこと

## 5. メール末尾の表示ひな形(TARGETS の全メール下書きに入れる)
```
───────────────
本メールは、貴塾のウェブサイトに事業用としてご公開されているメールアドレス宛にお送りしています。
今後このようなご案内を希望されない場合は、このメールに「配信停止」とご返信ください。以後お送りしません。
送信者: 【名称: 👤記入(契約名義人の氏名)】(内申点・倍率計算サイト「my-naishin.com」運営)
住所: 【住所: 👤記入】
連絡先(ご意見・苦情・お問い合わせ): naishin.dev@gmail.com
```
(連絡先メールアドレスは既存の運営者連絡先。差し替える場合は👤が決める)

## 6. 送信の運用ルール
- Gmailからの送信は**1日25通まで**(👤のGoogleアカウント保護。AdSense・Search Consoleと同一アカウント)。残りはフォーム
- 同一組織(運営会社が同じ複数教室)には**1社1通**。何度も送らない。返信が無い相手への**追い送信は1回まで・1週間以上空ける**
- 個人情報: 生徒の個人情報を塾に渡さない。この枠はリンクだけ
- 特商法: 相手が事業者(塾)のB2B営業なので、消費者向けの通信販売規制は通常適用されない(ただし虚偽・誇大な表示はしない・景品表示法/不正競争防止法の観点で「効果の約束」「他塾の誹謗」は書かない)
- 文面・添付・PR表記: 枠は「PR」明記(ステマ規制の対象は掲載側だが、こちらの表示義務としても守る)
