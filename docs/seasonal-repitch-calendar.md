# 季節イベント連動・再打診カレンダー（AA-4）

[[fable5-fullaccel-backlog-2026-07]] TIER AA-4。7月の売り込みと1月の倍率公表週の「御県の倍率速報
まとめました」は同じ相手でも別物（後者はニュース即時性がある）。X-2/X-5/X-6/X-7の全標的に対し、
1通目送信日からの経過だけでなく「次に来る季節フック」を事前に用意しておくことで、AA-1の追撃
（催促ではなく追加価値の提示）を年間を通じて途切れさせない。**送信は👤の判断・実行のみ**。

## 1. 冬フック台帳＝都道府県別「倍率確定情報 公表週」マップ

Y-6（[[fable5-fullaccel-backlog-2026-07]] TIER Y）で46都道府県の公立高校入試競争率データを
一次ソース（教育委員会公式PDF）から実際に取り込んだ際、**各県の資料に記載されていた公表日を
副産物としてそのまま記録できる**（`src/data/competition-rates/*.ts`のヘッダーコメント・
`sources[].docTitle`）。これは架空の予測ではなく、令和8年度（2026年度）実施分で実際に確認した
一次ソースの公表日そのものである。

⚠️**年度による揺れの注意**: 都道府県ごとに「志願変更後の確定出願者数」を公表する日は、その年の
出願スケジュール（学力検査日・志願変更受付期間の設定）に応じて数日〜1週間程度前後する。下表は
**令和8年度（2026年度）実施分の実測日**であり、次年度（令和9年度）の正確な日付は当該県の
入学者選抜実施要項が新たに公表され次第、都度確認すること（本表は「だいたいこの週」という
アウトリーチのタイミング設計用の目安。Y-11「冬の倍率速報体制」で使う取込スクリプトの対象URL台帳は
別途これとは独立に年度更新が必要）。

## 2. 冬フック文面（レーン別・[[aa1-followup-templates]]の季節版拡張）

[[aa1-followup-templates]]の5レーン構成をそのまま踏襲し、「追加価値」を1月下旬〜3月の
**倍率速報という即時性のあるニュース性**に差し替える。共通ルールは同じ（催促語彙禁止・
差分が無い週は送らない・Re:で返信・3-5文で短く）。実際に送る際は宛先ごとに固有名詞・リンク・
数値を差し込んで個別化すること。

### レーン1: b2b-saas（EdTech/模試会社/出版社等）

**トリガー**: 対象県の倍率確定情報公表日から1-2日後（上表参照）。

```
件名: Re: 内申点計算データAPI/MCPのご案内（My Naishin）

（会社名）ご担当者様

（県名）の公立高校入試、確定志願倍率が発表されましたね。
弊社でも同日中にデータを反映し、県別の倍率ページを更新しております。
https://my-naishin.com/（該当ツールURL）

冬季は最も検索が伸びる時期のため、もし（サービス名）様の方で
最新データを組み込みたいタイミングがございましたら、
API/MCP経由でリアルタイムに反映可能です。お気軽にご相談ください。
```

### レーン2: chihoshi（地方紙）

**トリガー**: 対象県の倍率確定情報公表日と同日〜翌日（ニュース速報性が命）。

```
件名: Re: （1通目の件名を踏襲）

（新聞社名）ご担当者様

本日（または昨日）、（県名）の公立高校入試確定志願状況が発表されました。
弊社でも学校別・学科別の倍率データを同日中に反映しております。
https://my-naishin.com/report/2026/（code）

記事作成の際の裏取りデータや、読者向けの倍率一覧としてご自由にご参照
いただけます。速報記事の締切がある場合は最優先でご対応いたします。
```

### レーン3: npo（教育系NPO）

**トリガー**: 2月中旬（山場の週・年1回のみでよい）。

```
件名: Re: （1通目の件名を踏襲）

（団体名）ご担当者様

ちょうど各県で入試の確定志願状況が発表される時期を迎えております。
弊社データセット（CC BY 4.0）も最新の倍率情報に随時更新しております。

進路指導や保護者支援の場で「今年の倍率」を扱う機会がございましたら、
必要な形式でのデータご用意も可能です。ご検討いただけますと幸いです。
```

### レーン4: mutual-link（相互リンク先）

**トリガー**: 2月中旬（山場の週・年1回のみでよい）。

```

（サイト名）運営者様

入試シーズン真っ只中ですが、貴サイトでも倍率関連の話題が

もし「倍率」「入試速報」等の文脈で一次情報として参照いただける

```

### レーン5: kyoiku-i（教育委員会等）

**トリガー**: 対象県の倍率確定情報公表日から1週間程度後（速報を反映した後の実績報告として）。

## 3. 春フック（白書2027・3月下旬〜4月）

冬フックが「速報性」なのに対し、春フックは「年間まとめ」の切り口。対象は主にb2b-saas/chihoshi。
X-3等で作成済みの技術記事・[[fable5-fullaccel-backlog-2026-07|白書]]の2027年度版が公開され
次第、以下の型で1通のみ（しつこくしない）。

```
件名: Re: （1通目の件名を踏襲）

（会社名/新聞社名）ご担当者様

令和8年度入試の全都道府県分データが出揃いましたので、
「内申点白書2027」として年間まとめを公開いたしました。
https://my-naishin.com/report/2027

来年度の受験生向け準備記事や、貴社サービスの年次アップデートの
参考資料としてご活用いただけますと幸いです。
```

## 4. 運用メモ

- **AA-1台帳との統合**: `data/outreach-ledger.json`の各エントリに`sourceTaskId`が記録されている
  ため、`lane`と`sentDate`から「この標的にはどの季節フックがまだ使われていないか」を人間が
  判断できる。自動判定ロジック（`daysBetween`等）への統合は季節境界の判定が複雑になるため
  見送り、当面は本ドキュメントを人間が参照する運用とする（over-engineering回避）。
- **Y-11との関係**: 上記の公表日マップはY-11（冬の倍率速報体制）が構築する「取込URL台帳」の
  種にもなる。ただしY-11は実データ取込の自動化を扱い、本ドキュメントは対外コミュニケーションの
  タイミング設計のみを扱う（役割は分離したまま）。
- **送信は👤のみ**: 本ドキュメントはテンプレの器と参考日程表であり、実際の送信・宛先選定・
  個別化は全て👤が行う。
