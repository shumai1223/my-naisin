# A-1: フォーム経由の県教委への問い合わせ文面（👤が手動で開いて送信）

- 起票: 2026-08-12（loop・T-S13A A-1継続）
- 対象: `ops/tasks/T-S13A-databank-product.md` A-1（47県利用条件台帳）のうち、
  問い合わせ窓口がメールでなくフォームのみの県。
- ⚠️ **これらのフォームはCookie必須のCMSが多く、loopのWebFetchでは中身を検証できない。**
  `data/outreach-queue.json`の`kyoiku-*-form`エントリのnote欄に記載の通り、
  氏名・年齢確認等の必須項目が未確認のフォームがある。**👤が実際にブラウザで開き、
  必須項目を確認したうえで下記本文を貼り付けて送信すること。**
- 文面はT-C1（`data/outreach-queue.json`の同名エントリ）にある「参照可否（被リンク）」を
  問う文面とは別物。**こちらはA-1専用＝「出典明記のうえでの第三者への再提供（データ商品への
  収録）」の可否を問う文面。** フォームの文字数制限がある場合は末尾の署名部分を削ってよい。

## 北海道教育委員会 学校教育局高校教育課

- フォームURL: https://www.dokyoi.pref.hokkaido.lg.jp/inquiry/?group=991&page=57219
- 備考: 「ご相談内容の種別」は「照会」を選択。氏名(全角)必須・メールアドレスは回答希望時のみ必須。年齢確認なし。

```
突然のご連絡失礼いたします。中学生・高校生向けの内申点計算・進路情報サイト「My Naishin」
（https://my-naishin.com）を運営しております、しゅうまいと申します。

貴教育委員会が公表されている公立高等学校入学者選抜の応募状況（募集人員・応募状況・応募倍率）を、
出典を明記のうえ当サイトに掲載させていただいております。

つきましては、このデータの利用範囲について一点ご相談がございます。現在、当サイトでは教育関係の
事業者様向けに、教育委員会公表資料に基づく入試関連データをAPI・CSV形式でご提供する仕組みの開発
を検討しております。この仕組みにおいても、貴教育委員会公表資料の募集人員・応募状況等のデータを、
出典（貴教育委員会名・公表資料名・URL）を必ず明記したうえで収録することを予定しております。

このような形（出典明記のうえでの第三者への再提供）でのデータ利用について、貴教育委員会として
問題ないか、あるいは何らかの条件・手続きが必要かどうか、ご教示いただけますと幸いです。

お忙しいところ恐縮ですが、ご確認のほどよろしくお願いいたします。

My Naishin 運営　しゅうまい　https://my-naishin.com
```
